# exam-cram · 考前突击复习教练

> 一个 Agent Skill。你给课程和考期，它找卷子、排考点、逐题讲透。

适用于 WorkBuddy / CodeBuddy，以及其他遵循通用 Agent Skills 规范（一个 `SKILL.md` + YAML frontmatter）的客户端。

---

## 它解决的具体问题

不是「帮你总结知识点」。是一个很窄但很真实的场景：

**没去上课，离考试只剩几天，要从零开始。**

这种时候最难受的不是没资料，是**资料太多不知道学哪个**，以及**看了解析还是不会**。

exam-cram 针对这两件事分别下手。

## 和普通 AI 解析的区别

普通解析从「解：」开始，省掉了三次「这里为什么想到这个」。

六段式把这三次补回来：

| 段 | 做什么 |
|---|---|
| ① 一句话翻译 | 题干翻成人话，先知道要干什么 |
| ② 定点 | 考哪个知识点，在整门课的什么位置 |
| ③ 前置补课 30 秒 | 只补这题用得着的那一点，不展开成章节 |
| ④ 手把手推 | 每步交代为什么这么想，**并标出卡点** |
| ⑤ 老师还能怎么问 | 2–3 个变式方向，防「换个说法就不会」 |
| ⑥ 保底写法 | 完全不会时写什么能拿步骤分 |

其中 **④ 的卡点** 是分水岭：

> 普通解析告诉你怎样做对，它告诉你**别人在哪里错、为什么错**。

比如「把开区间可导写成闭区间可导」「只背了概念不会用」——这类才是一个没上过课的人真正会掉进去的坑。

## 零基础怎么办：先过模型，别急着做题

这是 v1.3.0 补的一条路径，来自一次真实的失败。

第一版流程是「排完考点就开始讲题」。结果第一道题就要同时用四个新概念（相长干涉、折射率、光程、半波损失），用户当场断线，连问四轮「这个词什么意思」。

**题目是综合的，模型是单一的。** 所以对零基础的人，正确顺序是：

```
先把课程切成"模型" → 一个一个过 → 过完再回来做题
```

每个模型固定七步，一步不跳：

| 步 | 做什么 |
|---|---|
| ① 一句话定位 | 它是什么、用来干什么（从用途讲，不从定义讲） |
| ② 外观/结构图 | 标出题目里那个尺寸在哪 |
| ③ 图样/输出 | 先给「结果长什么样」的印象 |
| ④ 公式 | 先给骨架，再逐符号填空，**必须附四列符号表** |
| ⑤ 挂到旧模型上 | 主动说「这个和那个只差一处」 |
| ⑥ 一秒题 | 几个字就能答，答对才进下一个 |
| ⑦ 考场五行写法 | 可以直接抄到卷子上的答案 |

其中 **④ 的符号表** 是硬性要求，格式固定：

| 字母 | 图上是哪一段 | 题目常见说法 | 单位 |
|---|---|---|---|
| d | 缝板上两条缝的间距 | 双缝间距、缝距 | mm |
| L | 缝板到屏的距离 | 屏距、双缝到屏距离 | m |
| x | 屏上，从中央亮纹到某点 | 第 k 级到中央的距离、偏离中心 | mm |

第二列解决「这个字母在哪」，第三列解决「换个说法我认不出」，第四列解决单位混用。缺任何一列都会在考场上出问题。

**⑤ 是提分最快的一步。** 实测里，用户听到「迈克尔逊的 2 和薄膜题的 2 是同一个 2——光去了还要回来」之后，零提示独立算对了变式题。

全部过完还要做一次收束：一张全景图 + 一张「只有一列不同」的总表 + 一个通用四问。总表按 **「多走的那段路怎么算」** 组织，不按章节组织——这样能让人自己看出「三个模型公式完全一样」。

## 先查本校库，再搜全网

这是 v1.5.0 补的一层。顺序反了，后面全错。

**"本校"不是一个形容词，是三个可检索的字段：学期、学院、考试阶段。**

任何材料只要同时具备这三样，可信度就是最高级；缺任何一样，就要打折。

北邮的场景（[BYR Docs](https://wiki.byrdocs.org)，实测可用）：

| 入口 | 用途 |
|---|---|
| `byrdocs.org/?c=test&q=<课程名>` | 搜试卷 |
| `byrdocs.org/?q=<关键词>` | 搜全库，试卷 + 教材一起 |
| `wiki.byrdocs.org/exam/<学期>-<课程>-<期中｜期末>` | 文字版题目，免 OCR |

所以在开始之前，技能会先问三件事——**学院、年级、课程全名**：

| 信息 | 真正的作用 | 缺了会怎样 |
|---|---|---|
| **学院** | 决定**哪份卷子是你的** | 同一门「数据结构」，计算机学院、电子工程学院、国际学院、未来学院各有各的卷子。选错等于拿别人的考纲复习 |
| **年级 + 当前学期** | 推算这门课开在第几学期，**锁定该看哪几年** | 会去翻五六年前的卷子，命题风格早变了 |
| **课程全名** | 同一门课常有多个叫法 | 搜不到，误判成"库里没有" |

> **年级的用法是"缩小批次"，不是"挑卷子"。** 大三上要考一门大二下开的课，就重点看两年前的那一批。选哪份卷子靠学院，看哪几年靠年级。

顺带一件事：库里还有**教材原书**（带出版社、ISBN、版次），这是做"课件对不对"交叉验证最省事的来源——能确认是不是同一版。

不是北邮的学生，按同一思路找（`<学校> 试卷库`、`site:edu.cn <学校> <课程> 试卷`）。判定标准一样：能不能拿到「学期 + 学院 + 阶段」这三样。

## 五类学科，五套讲法

这是 v1.4.0 补的一层。原因很直接：同一套话术在物理上有效，在法学上会失效。

| 族 | 典型课 | 真正卡在哪 | 分从哪来 |
|---|---|---|---|
| **A** 计算理科 | 高数、大物、电路 | 符号层 + 实物层（不是公式） | 步骤分、统一单位 |
| **B** 图形经管 | 微观/宏观、金融 | 术语太像 + 图形语言 | 作图踩点、简答三段 |
| **C** 记忆人文 | 思政、法律、教育 | 名词精确度 + 答题结构 | 分点作答、踩点给分 |
| **D** 代码工程 | 数据结构、网络 | 机制 + 手写能力（看懂≠会写） | 手写算法、画结构图 |
| **E** 医学机制 | 解剖、生理、病理 | 名词量 + 机制顺序（记不住其实是记混了） | 按环给分、成对对比 |

五族对应不同的**一秒题形态**（"变大变小" / "往哪边动" / "属于哪一类" / "输出是什么" / "升高还是降低"）、不同的**必画图**、不同的**保底写法**和**时间分配比例**。

判定优先级是 **材料特征 > 课程名 > 用户描述** —— 课程名有迷惑性，「经济数学」其实属于 A。

跨族课（生化、计量经济、医学统计）走「主族 + 副族」，主族定骨架，副族补差异。

## 你的课件可能印错了

这是 v1.4.0 补的第二层。上传的 PPT、讲义、复习提纲，是学生手上最像「官方」的东西，**但它不等于真理**。

实际读材料时遇到过：公式上下标在转 PDF 时丢失、中英两版对同一概念的表述不一致、例题数字代回去算不通。

所以课件一律当「待校验线索」：

| 级 | 做什么 | 什么时候 |
|---|---|---|
| **V1 内部一致性** | PPT 前后是否矛盾、多版之间是否冲突、**例题自己代一遍** | 拿到材料必做 |
| **V2 权威对照** | 教材原书 > 高校课程页（.edu）> 权威百科；≥2 个独立来源一致才算确认 | 讲某个考点前 |
| **V3 真题对照** | 真题答法优先于 PPT 表述 | 有卷子时 |

发现冲突后按五类处理（笔误 / 版本差异 / 学术争议 / 表述简化 / 无法判断），每类都明确要不要告诉学生。

**三条绝对禁止**：静默按错的讲 ／ 静默纠正不讲 ／ 编造「教材原文」「本校真题」。

> 第二条最容易被忽略：有些错误 PPT 是无害的（老师自己也这么讲、考试也这么答）。这时**不该改，但该提醒**——"课件这里写的是 A，学术上更准确是 B，你这门课按 A 答就行，别改。"

原则是**讲到哪，核到哪**，不做全量预校验。十份课件全核一遍，时间成本超过复习本身。

## 默认不问时间

这是 v1.6.0 改的，也是被用户当场指出来的一条。

原来开局会问「还剩几天、每天能学几小时」，然后打六折算出「你其实只有 9.6 小时」，再据此做取舍、劝你睡觉。

**跑了两门课之后发现，这套东西一次都没真正生效**：

| 环节 | 设计意图 | 实际发生 |
|---|---|---|
| 问时间 | 判定急救 / 冲刺 / 常规 | 问了，但后面按知识点往下走，再没回头看这个数 |
| 打六折 | 制造紧迫感、指导取舍 | 只制造了一次焦虑，没指导任何决策 |
| 分数账本 | 决定何时停手 | 从没触发过 |
| 劝你睡觉 | 防止通宵 | 从没说过，因为根本没有时间约束 |

根因很简单：**真实的学习是「一条一条往下走」的，不是「按小时切块分配」的。** 时间分层是为「考前 8 小时急救」那种极端场景设计的，但绝大多数使用场景并不是那个。

所以现在：

- **默认不问时间**，不算小时，不做分值取舍，不劝停，按知识点顺序往下走
- 时间分层能力**完整保留**，但只在你自己说出「只剩两天」「今晚必须看完」这类话时才启用
- 判定标准写死为「用户主动提」，并且补了一句：**问了才说的不算主动提**

## 先梳理，再排序

v1.6.0 之前只做「排序」——给一张按分值排好的考点表。问题是学生拿到这张表，不知道这些考点之间什么关系，换个问法就找不到该用哪一块。

所以 Stage 2 拆成了两步：**2a 梳理 → 2b 排序**。

梳理产出的是三样东西：

**① 一条主线**——这门课在讲什么，一句话。并判定它的结构类型：

| 结构 | 目录长什么样 | 主线怎么画 |
|---|---|---|
| 因果链 | 多「形成 / 影响 / 导致」 | 箭头串起来，每环写为什么 |
| 流程链 | 多「步骤 / 流程」 | 编号步骤，每步写输入输出 |
| 分类树 | 多「分类 / 类型 / 体系」 | 树状，每层写划分标准 |
| 参数骨架 | 多「XX 效应 / XX 干涉」 | 骨架公式 + 「只有一列不同」的表 |

**② 每个知识点的五要素**，其中第 2 栏是关键：

| 要素 | 写什么 |
|---|---|
| 一句话定义 | 不用术语解释术语 |
| **判断信号** | **题里出现什么，就该想到它** |
| 易混项 | 「看到 A 容易想成 B，区别在 ___」 |
| 对应题型 | 选择 / 判断 / 计算 / 简答 / 作图 |
| 前置 | 依赖哪个更早的知识点 |

学生缺的从来不是定义，是「看到题里出现什么，就该想到用这个」。所以第 2 栏写不出来，就说明这个知识点还没梳理通。

**③ 三张成品图**——总览图、只有一列不同的对比表、看到 X 用 Y 的判断流程图。最后那张是考场上的救命稻草，它把「回忆」变成「走流程」。

> **梳理和做题的时间比是 20% / 80%。** 梳理是为了让做题时知道该用哪块，不是为了写一份漂亮笔记。

## 只在一种情况下才做取舍

用户自己说了明确的截止时间。那时才启用：打六折算真实小时、按分值排优先级、标出该放弃什么、以及劝你睡觉。

通宵的账是这么算的：多学 4 小时，换考场反应速度下降 30%，通常净亏。所以那时候它还是会说「剩下的放弃，去睡」。

但那是**例外路径**，不是默认路径。

## 用法

在对话里直接说需求，不用记命令：

**有卷子**

> 用 exam-cram 帮我复习《管理会计》，11 月 12 号上午考，还剩 5 天，每天能学 6 小时，目标及格。卷子在附件里。

**报了学院和年级（会先查本校试卷库）**

> exam-cram，复习《数据结构》，北邮计算机学院，大二上，11 月 20 号考，还剩 4 天，每天 5 小时，稳过就行。

**一份卷子都没有**

> exam-cram，复习《数据结构》，XX 大学，教材是严蔚敏版，后天考，实际只有 8 小时，能过就行。卷子我搞不到。

**只想讲一道题**

> exam-cram，这道题给我讲透（贴题目或拍照）

没自动认出来时，开头写上 `exam-cram` 就一定会触发。

## 它产出什么

在你自己指定的目录下建 `复习-<课程>-<考试名>/`：

| 文件 | 作用 |
|---|---|
| `00-作战计划.md` | 学科族判定、主线一句话、按什么顺序往下走 |
| `01a-知识点全图.md` | **主线 + 五要素明细 + 分叉点 + 三张图**（主材料） |
| `01b-考点热力表.md` | 考点排序，划 60% / 80% / 95% 三条线（有试卷才做） |
| `01c-模型卡片/<模型>.md` | 按七步写的单模型讲解 + 符号表（零基础主材料） |
| `02-讲题卡片/<考点>.md` | 逐题六段式讲解 |
| `03-自测记录.md` | 每题对错、错因归类 |
| `04-保底清单.md` | 考前 20 分钟只看这一页 |
| `materials.md` | 材料清单、可信度分级、**材料校验记录** |
| `05-勘误表.md` | 课件里**会影响得分**的错误（只在疑点会改变答案时出） |

## 它是怎么排序的

```
Score = 0.35 × 频率 + 0.30 × 分值占比 + 0.20 × 新近度 + 0.15 × 章节权重
```

样本不足时自动降级：只有 1 份卷子就弃用频率，完全没有本校卷就改成「章节权重 + 通用先验」，并且**在表里标注这是推断，不是统计**。

按累计分值划三条线：

- 60% —— 及格底线
- 80% —— 稳过线
- 95% —— 冲高线

线的意义是给一个心理锚点：**复习到这里就能及格了**。否则人会以为要全学完，然后直接摆烂。

## 取题：两条路

**有卷子** → 解析。OCR 校对、切题、六字段抽取、同题归并。

**没卷子** → 联网检索，按性价比排来源：教材课后题 > 老师提纲 > 同教材异校卷 > 考研真题 > 院系官网 PDF > 学科垂直站 > 文库。

每一份材料都标可信度（✅ 本校 / 🟡 同课异校 / ⚠️ 同教材 / 🔵 考研 / ⛔ 假真题），**混进统计会让整张表失真**。

## 诚实边界

这个技能不承诺这几件事，也不假装能：

- **不保证押中。** 考点排序是启发式推断，不是预测。它做的是把有限时间分到期望收益更高的地方，仅此而已。
- **「你们学校」的真题经常搜不到。** 大学专业课卷子基本不外流，公网命中率约 20–40%。搜不到时会明说，改用教材课后题和同教材异校卷替代，**不会编一份卷子出来**。
- **网上大量「2026 年 XX 期末试卷」是假的。** 没有校名、题题带解析、机械排列的那种，多半是题库拼的。技能里加了识别规则，见到就排除。
- **它不保证你老师给的课件是对的。** 所以会先核再讲，发现问题是会明说的——包括「课件写错了」和「课件没错但学术上有另一种说法」这两种。核不到的会直接说「我不确定，以你们教材为准」，不会硬给一个数。
- **它不能替代你真的动手做题。** 看懂了和会做之间隔着一次动手。自测环节就是防这个的，但你可以骗过它。

**English TL;DR** — exam-cram is an Agent Skill for exam prep. It **does not ask how many days you have left** — real studying is linear, not an hourly budget, and time-slicing only produced anxiety. Instead it first maps the course: one main thread (causal chain / process / classification tree / parameter skeleton), every knowledge point in five fields where the crucial one is *"what in the question tells you to use this"*, plus a separate list of the confusions that actually cost marks. It checks your own university's exam archive first (school + department + year are three searchable fields, not background info), then falls back to textbook problems. It routes to one of five subject archetypes, and treats uploaded slides as **unverified leads** — internal consistency and worked-example recomputation first, authoritative cross-check for load-bearing claims, conflict resolved through an explicit decision tree, never silently teaching a wrong formula.
