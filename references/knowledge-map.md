# 知识点梳理

## 这一步为什么必须在排序之前

**排序回答"先学哪个"，梳理回答"这门课到底在讲什么"。**

顺序反了会出两个问题：

1. 学生记了一堆孤立的知识点，**没有骨架**。考场上换个问法，不知道这题该用哪一块
2. 热力表上的排名对他没有意义，因为他不知道第 3 名和第 7 名是什么关系

所以先给结构，再给优先级。**梳理是理解，排序是取舍。**

> 实测：把十条原理压成一张"编号 / 原理 / 一句话 / 考法"的表，学生能自己复述；如果把同样内容按 PPT 页码顺序讲 31 页，讲完他一句也说不出。

## 一、先找主线：这门课在讲一条什么链

**不要按目录顺序罗列知识点。** 目录是编写顺序，不是理解顺序。先找出这门课的主线结构，再往里挂知识点。

四种常见结构，判断错了表格排得再整齐也没用：

| 结构 | 长什么样 | 典型课程 | 主线怎么画 |
| --- | --- | --- | --- |
| **因果链** | A 导致 B，B 导致 C | 经济学、生理、历史、病理 | 箭头串起来，每环写"为什么" |
| **流程链** | 第一步 → 第二步 → 第三步 | 算法、司法程序、实验操作 | 编号步骤，每步写"输入什么、输出什么" |
| **分类树** | 大类 → 子类 → 具体 | 管理、生物分类、法律体系 | 树状，每层写"划分标准是什么" |
| **参数骨架** | 一个公式，换不同参数就是不同模型 | 物理、化学、电路 | 骨架公式 + 一张"只有一列不同"的表 |

### 怎么快速判断

**看目录里的动词和名词。**

- 目录全是"XX 的形成""XX 的影响""XX 导致" → **因果链**
- 目录全是"第一步""流程""步骤" → **流程链**
- 目录全是"XX 的分类""XX 的类型""XX 体系" → **分类树**
- 目录全是"XX 干涉""XX 衍射""XX 效应" → **参数骨架**

一门课也可能混用：主结构一种，某一章内部另一种。**主结构决定整门课的图，章的内部结构决定那一章的图。**

### 主线的写法

一句话说清，不超过 30 字：

```
微观经济学：稀缺 → 要选择 → 机会成本 → 分工与交换 → 价格如何形成 → 价格失灵时怎么办
波动光学：一束光分成两束 → 走过的路不一样长 → 叠加时亮或暗 → 换装置只换"路差怎么算"
数据结构：数据怎么存 → 决定能怎么查 → 决定快不快
```

**检验标准：用户能不能不看材料，用一句话说出这门课在讲什么。** 说不出就是没梳理完。

## 二、每个知识点给五要素

这是梳理的最小单位。**五栏缺一栏都不算梳理完**，尤其第 2 栏。

| 要素 | 写什么 | 为什么必须有 |
| --- | --- | --- |
| **① 一句话定义** | 不用术语解释术语 | 定义里带术语等于没定义 |
| **② 判断信号** | 题里出现什么，就该想到它 | **这一栏是学生真正缺的**，不是定义 |
| **③ 易混项** | 和谁最像，差在哪一个字 | 丢分几乎全在这里 |
| **④ 对应题型** | 选择 / 判断 / 计算 / 简答 / 作图 | 决定要练成什么样 |
| **⑤ 前置** | 依赖哪个更早的知识点 | 卡住时知道该往回退到哪 |

### 第 ② 栏怎么写（最重要）

**不要写"它是什么"，要写"什么信号触发它"。**

| 坏（等于没写） | 好 |
| --- | --- |
| 机会成本是放弃的最优选择的价值 | 题里出现"放弃""本来可以""如果不做这个"→ 用机会成本 |
| 比较优势是机会成本较低 | 题目给了两个人的产量表，问"谁该生产什么"→ 算机会成本 |
| 半波损失是反射时的相位突变 | 题目里有两个反射面，且两侧 n 不同 → 查半波损失 |

写不出来的知识点，说明自己也没想清楚它在什么时候用。**这种知识点要么补，要么标"仅概念题"**。

### 第 ③ 栏怎么写

固定句式：**"看到 A，容易想成 B，区别在 ___"**

```
看到"需求变动"，容易想成"需求量变动"，区别在：前者是整条线搬家（非价格因素），后者是沿线上滑动（价格变了）
看到"绝对优势"，容易想成"比较优势"，区别在：前者比产量高低，后者比机会成本高低
看到"消费者剩余"，容易想成"总剩余"，区别在：总剩余还要加上生产者剩余
```

**一门课真正拉分的就那么几个分叉点。** 把它们集中列成一张清单，比散在各章里讲十遍有用。

## 三、三张图（梳理的成品）

梳理完不是一堆文字，是三样可以直接看的东西：

### ① 总览图（结构）

一张图看清这门课分几块、块之间什么关系。可以是：
- 因果链的箭头图
- 分类树的层级图
- 参数骨架的"全景 + 分叉"

**要求**：一眼能看出"哪几块是并列的，哪几块是有先后的"。

### ② 对比表（只有一列不同）

把最容易混的几个东西放一张表里，**除了一列之外全部相同**。

```
| 模型 | Δ 怎么算 | 屏上长什么样 | 公式 |
| 薄膜 | 2nd + λ/2 | 整片一个颜色 | ... |
| 劈尖 | 2nd + λ/2 | 等间距直条纹 | ... |
| 牛顿环 | 2nd + λ/2 | 同心圆环 | ... |
```

这张表的威力在于：**让人自己看出"三行只有一列不同"**，比讲十遍"注意区分"有效。

### ③ 判断流程图（看到 X → 用 Y）

把"拿到题该往哪想"变成一条可执行的分支：

```
题目给了产量表？
├─ 是 → 是"每小时产量"还是"生产一个要几小时"？
│        ├─ 每小时产量 → 机会成本 = 另一个的产量 ÷ 这个的产量（倒着除）
│        └─ 每单位时间   → 机会成本 = 这个的时间 ÷ 另一个的时间（顺着除）
└─ 否 → 给了机会成本直接比大小
```

**这张图是考场上的救命稻草。** 它把"回忆"变成"走流程"，卡住时照着走就行。

## 五、梳理到什么程度算完

三个检验，**全部通过才算完**：

1. **主线检验**：不看材料，能说出这门课在讲什么（一句话）
2. **分块检验**：能说出分几块、每块解决什么问题
3. **分叉检验**：能说出最容易混的 3 对概念，以及区别在哪

做不到就继续梳理。**但不要为了梳理而梳理** —— 第一档（必考）的知识点梳理到"能写出判断信号"就够了，第三档的可以只留名字。

> 时间不够时，梳理和做题的取舍：**梳理占 20%，做题占 80%。**
> 梳理是为了让做题时知道"这题该用哪块"，不是为了做一份漂亮的笔记。

## 六、常见错误

| 错误 | 后果 | 正确做法 |
| --- | --- | --- |
| 按目录顺序罗列 | 学生记不住，也没有骨架 | 先找主线，再挂知识点 |
| 只写定义不写判断信号 | 学生认得这个词，但做题想不到用 | 第 ② 栏必须写"什么信号触发它" |
| 知识点粒度太细 | 一门课列出一百条，等于没梳理 | 以"一个考点"为单位，通常 15–40 条 |
| 粒度太粗 | 一条就叫"第三章"，无法使用 | 每条应该能对应 1–3 道题 |
| 没有易混清单 | 分叉点全丢在正文里，学生自己找不到 | 单独列一张表 |
| 梳理完不做题 | 看着都懂，动手全废 | 梳理 20% + 做题 80% |
