# 六段式讲题法

## 为什么是六段

零基础学生面对一道题的困境不是"看不懂答案"，是**不知道答案的第一行为什么是那一行**。答案通常从"解："开始，中间省掉了三次"这里为什么想到这个"。

六段式的作用：把省掉的推理补回去，并且补在最需要的位置。

**顺序不可调换。** 先翻译再推导，是因为看不懂符号的人需要先知道目标；先定点再补课，是因为不知道概念归属的人，补了也记不住。

---

## ① 一句话翻译

把题干翻成人话，≤40 字。

规则：
- 把符号、术语全部换成日常说法
- 只描述"要你干什么"，不解释怎么做
- 如果题干的坑藏在措辞里（比如"至少""恰好""不高于"），翻译时直接点出来

示例：
- 原题：「设 f(x) 在 [a,b] 连续，(a,b) 可导，且 f(a)=f(b)，证明存在 ξ∈(a,b) 使 f'(ξ)=0。」
- 翻译：「一头一尾一样高的曲线，中间肯定有一个点，切线是水平的。」

---

## ② 定点

一句话说清这题考什么、在哪。

格式：
```
考点：<知识点名>（热力表 #<编号>）
位置：第 <N> 章「<章名>」→ 前置是 <上一环>
```

"前置是 X"这一句很关键 —— 它告诉学生"听不懂是缺了 X"，而不是"我笨"。

---

## ③ 前置补课（30 秒版）

只补这题用得到的那一点，三行讲完：

```
为什么要有它：<这个工具解决什么麻烦>
一句话定义：<去掉修饰语的本体>
符号对照：<公式里每个字母是什么>
```

**禁止**展开成教材章节。**禁止**补充"相关延伸"、"历史背景"、"注意事项一二三四"。

判据：补完之后能直接进入第 ④ 段，不补就进行不下去。多一个字都是浪费。

---

## ④ 手把手推（含卡点）

逐步走。每一步都必须交代**为什么是这一步**，而不是只写做了什么。

固定结构：

```
第 1 步：看到 ____，想到 ____。
         （这是条件反射，来源是 ____）
第 2 步：____ → ____。
         （为什么能这么换：____）
⚠️ 卡点：90% 的人在这里会 ____。
         错因是 ____。正确做法是 ____。
第 3 步：……
```

**卡点标注是分水岭。** 普通解析告诉你怎么做对，讲透要告诉你别人怎么错。没有卡点的讲解等于没讲。

卡点从哪来：
- 该步骤涉及的条件限制（定义域、适用前提、符号方向）
- 两个易混概念的边界
- 学生最常见的错误直觉
- 跳步的地方（原答案省掉的中间式）

---

## ⑤ 老师还能怎么问

给 2–3 个变式方向，每个只写"怎么下手"，**不给完整解**。

四种变形，按这门课的命题风格挑：

| 变形 | 怎么变 | 例子 |
| --- | --- | --- |
| 改条件 | 去掉一个前提 / 换成反向 | "如果去掉连续，还成立吗" |
| 反向问 | 已知结论求参数 | "如果告诉你 ξ 存在，怎么反推 a" |
| 加一层 | 套在别的情境里 | "把它放进物理背景里，那就是瞬时速度为 0" |
| 换情境 | 同类不同皮 | "换成经济学里的边际收益" |

目的：防止"换个说法就不会"。

---

## ⑥ 保底写法

如果考场上完全不会，写什么能拿步骤分。

必须具体，不能写"写出相关公式"这种废话：

```
必写：____（能拿 ~X 分）
可写：____（能拿 ~Y 分）
别写：____（会扣分或被判错）
```

对理工科，最有效的三件套：**写公式 / 画图 / 列已知未知**。
对文科，最有效的三件套：**写定义 / 分点 / 举一个例子**。

---

## 收尾：一句话钩子

≤20 字，考场回忆用。

不是总结，是**触发器**。写成一个能勾出整段推理的短语。

- 好：「一头一尾等高 → 必定有个平点」
- 坏：「本题考查罗尔定理的应用及其几何意义」（这是废话）

---

## 好 / 坏对照

**坏**（典型 AI 解析，占 80%）：

> 由题意知 f(x) 在 [a,b] 上满足罗尔定理的条件，故存在 ξ∈(a,b) 使得 f'(ξ)=0，证毕。

问题：没说为什么想到罗尔定理；没说罗尔定理为什么长这样；没说这题换个条件会怎样。学生看完只会背结论。

**好**（六段式）：

> **① 翻译**：一头一尾一样高的曲线，中间必有一个点切线水平。
>
> **② 定点**：罗尔定理（热力表 #03）。位置：第 3 章微分中值定理 → 前置是"费马引理"。
>
> **③ 前置补课**：为什么要有它 —— 想由"两端相等"推出"中间有个特殊点"，但手头只有导数，需要一个桥把这个等式翻译成导数为 0。一句话定义：满足三条件则内部必有驻点。符号对照：f(a)=f(b) 是两端等高，f'(ξ)=0 是那点切线水平。
>
> **④ 手把手推**：
> 第 1 步：看到"两端函数值相等"+"要求某点导数为 0"，想到罗尔定理。（条件反射：等式条件 → 中值定理 → 找驻点。这是本章唯一的破题方向。）
> 第 2 步：逐条核对三个条件：闭区间连续、开区间可导、端点相等。三条必须**分开写**，写在开头 —— 这是得分点。
> ⚠️ 卡点：绝大多数人错在把"开区间可导"写成"闭区间可导"。闭区间端点谈不上导数，写了算错。另有约 20% 的人漏写"连续"直接引用，扣 2 分。
> 第 3 步：引用定理得结论，写"故存在 ξ∈(a,b) 使 f'(ξ)=0"。
>
> **⑤ 还能怎么问**：去掉"连续"，结论还成立吗（不成立，给反例思路）；改成"证明存在 ξ 使 f'(ξ)=k"（构造 g(x)=f(x)−kx）；改成"存在 ξ 使 f'(ξ)=f(ξ)"（构造 e^{−x}f(x)）。
>
> **⑥ 保底写法**：必写三条条件核对 → 约 4 分。可写定理名与结论 → 再 2 分。别写"由罗尔定理显然可得" → 判卷老师看不到条件，可能只给 1 分。
>
> **钩子**：一头一尾等高 → 中间必有个平点。

字数：约 620 字，在 400–900 区间内。

---

## 篇幅纪律

| 情况 | 处理 |
| --- | --- |
| < 400 字 | 通常漏了卡点或前置补课，补回来 |
| 400–900 字 | 正常 |
| > 900 字 | 在堆教材。删掉所有"延伸""补充说明""值得注意的是" |
| 用户明确要"一句话版本" | 只给 ⑥ + 钩子，其余压缩成 3 行提纲 |

---

## 多题批量讲时的节奏

不要一次贴 5 道题的完整六段式 —— 信息过载，等于没讲。

正确节奏：

```
先讲 1 道（六段式全开）
→ 立刻出 1 道变式（Stage 4）
→ 学生答完，判分
→ 再讲第 2 道
```

同一考点下的第 2、3 道题可以压缩：① ③ 合并成一句，只保留 ④ ⑤ ⑥。

## 非计算类题目的调整

理工科之外的课程，六段式的映射：

| 段 | 文科 / 商科 / 法学 / 医学怎么讲 |
| --- | --- |
| ① 翻译 | 把题目问的"题眼"抽出来：是要你辨析、还是论述、还是给方案 |
| ② 定点 | 对应哪一章的核心争论或框架 |
| ③ 前置 | 只补那个必须的术语，用一句大白话 + 一个反例 |
| ④ 推 | 不叫"推导"，叫"答题骨架"：先亮观点 → 再给依据 → 再分层 → 再收 |
| ⑤ 变式 | 换问法、换主体、加一个限定条件 |
| ⑥ 保底 | 写框架 / 分点 / 举一个具体例子，通常就有基础分 |

文科的"卡点"通常是：只背了概念不会用、答题不分点、观点没有依据、把"是什么"答成了"为什么"。
