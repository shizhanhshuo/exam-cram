# 概念辅导模式（不做题，只讲通）

## 这条路径是什么

学生不是来刷题的，是来**把一门课的概念从零建立起来**的。

典型场景：

- "这门课我没上过，你先给我讲一遍"
- "我基础差，概念都不懂"
- 手上一道真题都没有，或者明确说"先别做题"
- 老师划了范围，但学生连范围里的名词都认不全

与刷题路径的区别：**刷题是"从题回到概念"，概念辅导是"从概念推到题"。**
顺序反了，学生会变成"每道题都眼熟，换个问法就空白"。

---

## 一、节奏：一块 → 一图 → 一题

**这是整个模式唯一的流程，不许改。**

```
① 讲一块（一次只讲一个能独立站住的块）
② 该画图就画图（关系、结构、变化，一律用图，不用文字描述）
③ 立刻出一秒题（一句话能答完）
④ 学生答对 → 下一块；答错 → 换讲法讲同一块，然后重出
```

三步缺一不可。缺 ③ 就等于没讲——学生点头只代表"听懂了这段话"，不代表"会用了"。

### 「一块」到底多大

判据只有一条：

> **讲完这一块，能不能问出一个"两个词就能答"的问题？**

- 能 → 块大小合适，继续
- 问不出，或者只能问"懂了吗" → 这块太大或太散，切小

反例（块太大）：「讲消费者理论」——一次讲完预算线、无差异曲线、最优选择、两个效应，学生全程点头，一小时后再问全忘。
正例（块合适）：「预算线的两种移动」——讲完立刻能问"收入变还是价格变？"

一次消息里最多两个块。超过就是灌。

---

## 二、一秒题的设计规范

一秒题是本模式的核心工具，不是随口问的。

### 硬性要求

| 项 | 要求 |
| --- | --- |
| 题干长度 | 一到两句，不带计算 |
| 答案长度 | **一个词到两个数** |
| 考查范围 | **只考刚讲完的那一个判断**，不牵连其他块 |
| 判分 | 必须明确说对错，不许含糊 |

### 好题与坏题

```
好：MRS=3，Px/Py=2，该多买 X 还是多买 Y？        （两个字）
好：收入 100，Px 从 5 涨到 10，两个截距各是多少？  （两个数）
好：价格下降，替代 +3 收入 −2，属于哪类品？       （三个字）

坏：请说明消费者选择理论的基本内容。              （这是考试题，不是一秒题）
坏：计算最优消费组合并求出效用。                  （这是计算题，考的是耐心）
坏：懂了吗？                                      （无效，学生一定说懂）
```

**一秒题的题干必须能被复述。** 学生看完能在脑子里重念一遍，才答得出来。

### 题目来源：只考"判断信号"

每个知识点都有一句判断信号（见 `knowledge-map.md` 五要素）。一秒题就是**把判断信号反过来问**：

```
知识点：税收归宿
判断信号：谁更难走开，谁承担更多
一秒题： 吸烟者戒不掉、烟厂随时能转产，这 10 元税主要落在谁身上？
```

如果某个知识点写不出判断信号，说明它还没被讲成"可用的东西"，回去重讲。

## 三、答错了怎么办：改讲法，不许重复

**唯一禁止的动作：把刚才那段话再说一遍。**

连续两题同方向答错 → **判定为讲法缺陷，不是学生的问题。** 立刻执行下面三步。

### 三步换法

```
第 1 步：改口径。用一句话说明"我上一句给错了 / 给得太粗"，把责任揽过来。
         （这一步不能省。学生一旦开始怀疑自己，后面讲什么都听不进去。）

第 2 步：换一个不同层级的讲法，按下面顺序往下退。
         层级 1：给机制（为什么会这样）
         层级 2：给钱的流水账（代入具体数字走一遍）
         层级 3：给极端情形（把一方设成"完全不动"，剩下的关系就显形了）
         层级 4：给日常类比（菜市场、租房、抢票）

第 3 步：换一道同结构、不同皮的题重出。答对了才算过。
```

### 判据：这次的错是"讲法"还是"缺口"

```
换个说法就懂了        → 讲法问题，记下来，这个说法要写进 references
换三种说法都不懂      → 知识缺口，退一层补前置（走 foundations.md）
```

### 已确认的高危讲法（不要再用）

- **只给结论式口诀，不给机制**。例：「弹性小的一方承担多」——学生顺着推会得到反答案
- **两句口诀互相矛盾**。给了"对方越灵活你越吃亏"，又给了"弹性小的一方承担多"，必错
- **用术语解释术语**。「边际替代率递减，所以无差异曲线凸向原点」——两个词都不懂，等于没说
- **数字算对了就以为讲通了**。学生能跟着算，但换个包装就不会，说明机制没进脑子

## 四、什么时候从概念切到做题

不能一直讲概念，也不能太早切。判据三条，**全部满足才切**：

```
① 同一考点的三秒题连对 3 道（换过皮的，不是同一道）
② 学生能自己说出"看到 X 就想到 Y"（不用提示）
③ 学生主动问"那这个怎么考" —— 这是最可靠的信号
```

第 ③ 条出现时，立刻切，不要因为"还有两块没讲"而拖延。**学生想做题的时候讲概念，是最浪费的时刻。**

切换后进入 `teaching.md` 的六段式。

## 五、常见失败模式

| 症状 | 病因 | 处理 |
| --- | --- | --- |
| 学生全程点头，隔天全忘 | 一次讲了太多块，没有一秒题锚定 | 退回上一块，重新走"一块一图一题" |
| 学生能复述定义，但不会用 | 只讲了"是什么"，没讲"看到什么该想到它" | 补判断信号，重出一秒题 |
| 同一方向连错三题 | 讲法反了或太粗（**先怀疑自己**） | 走三步换法，改口径 → 换层级 |
| 学生开始说"算了""差不多吧" | 难度跳太快，挫败感累积 | 退到层级 4（日常类比），先把信心接回来 |
| 讲得很顺但学生不说话 | 一秒题太难，或答案太长 | 把题缩到两个词能答 |

## 六、输出物

概念辅导模式**默认不产出文件**。理由是：这条路径的产物是"学生脑子里的东西"，不是文档。强行生成一份笔记，只会变成另一份没人看的资料。

需要留档时只做一件事：

```
每讲完一章，输出一张「判断信号表」：知识点 | 看到什么该想到它 | 易混项
```

一张表，不超过 15 行。多一个字都不写。
