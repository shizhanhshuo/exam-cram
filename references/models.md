# 按模型过一遍（Stage 2.5 操作手册）

> 来源：2026-11-13 ~ 11-15 大学物理 C（下）实战。用户零基础，五道题，但课件覆盖十个模型。
> 原流程（直接按题讲）走不通：讲第 2 题时需要同时用「相长干涉」「折射率 n」「光程 2nd」「半波损失」
> 四个未定义概念，用户当场断线，连问四轮"什么叫…"。
> 改成按模型逐个过之后，用户在第 6、7、8 个模型上能自己答对。

---

## 一、什么时候走这条路径

**判据（满足任一即走）**：

- Stage 0.5 判定用户处于 L0 或 L-1 层（不知道现象、不知道实物）
- 考点覆盖的"模型"数量 > 题目数量（题少但知识点散）
- 用户明确说"一个一个部分来""先把基础补一下"
- 讲第一道题时就发现要引入 3 个以上新概念

**不走的情况**：用户有基础（L2 以上）、时间 < 4 小时、只需要背结论。那时直接按题讲更快。

---

## 二、先做一件事：把课程切成"模型"

模型 = **一个装置 / 一个场景 + 一套图样 + 一个公式骨架**。

切法：翻课件目录和例题，凡是"换了个装置就要换公式"的，各算一个模型。

以波动光学为例，课件里有十个模型，试卷只考了五个：

| 干涉类 | 衍射类 |
| --- | --- |
| 双缝、薄膜、劈尖、牛顿环、迈克尔逊 | 单缝、圆孔、光栅、光栅缺级 |

**切完立刻排出优先级**（用 Stage 2 的考点热力表），分三档：必补 / 该会 / 有余力再看。

零基础用户**只过第一档**。第二档在讲题时顺带带一句。第三档直接说"这几块放弃"。

> 不要贪。十个模型全过一遍是灾难，用户会在第五个放弃。**五个以内，讲透。**

---

## 三、单个模型：固定七步

顺序不可调，每步都短。

### 第 1 步 · 一句话定位（1 句）

**它是什么、用来干什么。** 不要从定义讲起，从用途讲起。

- ✅「迈克尔逊干涉仪是一台专门测量极小长度的仪器。」
- ❌「迈克尔逊干涉仪是利用分振幅法产生双光束以实现干涉的精密光学仪器。」（教材原话，等于没说）

### 第 2 步 · 外观 / 结构图（一张图 + 3–5 个部件）

画出来，或者用文字把部件摆出来。**必须标出题目里那个尺寸在哪。**

- 「缝宽 a 就是这条缝有多宽」——必须指到图上，不能只在正文描述
- 仪器类还要说**手碰哪里、读数在哪看**（可以省掉"原理"，不能省掉"操作"）

### 第 3 步 · 图样 / 输出（你能看到什么）

让学生先有"结果长什么样"的印象，再谈为什么。

- 单缝：中间一条特别宽
- 光栅：几根极细极亮的线 + 大片黑
- 牛顿环：内疏外密的同心圆环

**这一步是判断"他到底有没有建立图像"的关键。** 让他描述一遍，描述不出来就退回第 2 步。

### 第 4 步 · 公式（骨架 → 逐符号 → 数值）

**先给骨架，不给完整公式。**

```
某个尺寸 × sinθ = 级数 × 波长
```

骨架立住后再填空：

| 模型 | 填什么 | 算什么 |
| --- | --- | --- |
| 单缝 | a（缝宽） | 暗纹 |
| 光栅 | d（缝距） | 亮线 |
| 圆孔 | 1.22D（孔径） | 第一暗环 |

然后**必须给四列符号表**（见第四节，硬性要求）。

最后代数字。**代数字时同步做单位换算，不要留到最后。**

### 第 5 步 · 挂到旧模型上（1–2 句，这是提分最快的一步）

**主动指出新模型和某个已学模型"只差哪一处"。** 用户不需要学新东西，只需要知道"这个和那个像"。

实战有效的几个挂钩：

| 新模型 | 挂到 | 一句话 |
| --- | --- | --- |
| 劈尖 | 薄膜 | 同一个公式，只是膜厚从"处处一样"变成"慢慢变厚" |
| 牛顿环 | 劈尖 | 同一个公式，只是厚度按 r² 长，所以条纹内疏外密 |
| 迈克尔逊 | 薄膜 | 那个 2 是同一个 2：光去了还要回来 |
| 光栅 | 单缝 | 只差一个字母：a 换 d |
| 圆孔 | 单缝 | 只差一个 1.22 |
| 光栅缺级 | 光栅 + 单缝 | 两个公式撞在同一方向 |

> **这条的效果在实战里非常明显。** 用户在迈克尔逊那题上，听到"这个 2 和薄膜题的 2 是同一个 2"之后，立刻独立算对了变式题。

### 第 6 步 · 一秒题（答对才进下一个模型）

**设计规则（硬性）**：

- 只需**几个字**回答：一个数字、一个词、或"是 / 否"
- 只考**这一轮刚讲的那一件事**，不许综合
- **不许需要计算**（除非讲的就是计算）
- 答错**不出第二道同类题**，而是换讲法重讲那一件事

好的探测题：

| 场景 | 题 | 期望答案 |
| --- | --- | --- |
| 讲完疏密 | 「光从空气射进玻璃，是疏→密还是密→疏？」 | 疏→密 |
| 讲完级数编号 | 「第二级暗纹是从中央往外数第几条黑缝？」 | 2 |
| 讲完 d 和 a | 「d = 2000 nm，a = 500 nm，d/a 是几？」 | 4 |
| 讲完半波损失 | 「从膜 1.5 撞向玻璃 1.7，翻不翻？」 | 翻 |

坏的探测题（不要用）：
- 「你理解了吗？」——永远答"懂了"，信息量为零
- 「那这道题你会做了吗？」——综合题，答不上不知道卡在哪儿
- 需要三步以上计算的题——那不是验证概念，是验证算术

### 第 7 步 · 考场五行写法

给一段**可以直接抄到卷子上**的短代码块。不是解题过程，是**排版好的答案**。

```
两界面 n：1.0（空气）→ 1.5（膜）→ 1.7（玻璃）
上表面 1.0→1.5：疏→密，有半波损失
下表面 1.5→1.7：疏→密，有半波损失
两次抵消，故 Δ = 2nd
反射相长：2nd = kλ，k=1 → 2×1.5×d = 600 → d = 200 nm
```

**为什么必须有这一步**：学生"听懂了"和"卷子上写得出"是两回事。五行版把"懂"翻译成"可交付"。

## 四、符号表：硬性要求，不许省

**讲完任何模型，紧跟一张四列小表。** 这是 2026-11-15 实战定的规矩——用户连续四轮只问符号（x 是什么、d 和 a 是什么），说明"正文里用文字描述符号位置"这种讲法**完全不顶用**。

固定格式：

```
| 字母 | 图上是哪一段 | 题目常见说法 | 单位 |
```

示例：

| 字母 | 图上是哪一段 | 题目常见说法 | 单位 |
| --- | --- | --- | --- |
| d | 缝板上两条缝的间距 | 双缝间距、缝距 | mm |
| L | 缝板到屏的距离 | 屏距、双缝到屏距离 | m |
| x | 屏上，从中央亮纹到某点 | 第 k 级到中央的距离、偏离中心 | mm |

**四列各有不可替代的作用**：

- 第 2 列解决"这个字母在哪"（用户真正的问题）
- 第 3 列解决"题目换个说法我认不出"（丢分主因）
- 第 4 列解决单位混用

**同一模型被追问两次以上符号 → 直接补表，不再换说法解释。补表比换说法有效。**

另外：**新符号第一次出现时，必须先在图上指出来，再写进公式。** 反过来（先公式后解释）会让零基础用户直接放弃。

## 五、跨模型的三类"工具层缺口"

有些东西不属于任何模型，但会卡死所有模型。遇到就**单独抽一轮讲**，不要塞进模型里。

### 1. 单位换算

nm / μm / mm / m，相邻两档差 1000。

- 口诀：**单位变小，数字变大，每跨一档挪三位**
- 最常错：nm ↔ mm 隔了两档（10⁶），漏掉 μm 就会错一千倍
- 实战记录：用户把 2400 nm 答成 0.24 μm，少挪一档

### 2. 科学计数法的乘除

不要硬算小数。**数字除数字，指数减指数。**

```
600×10⁻⁹ ÷ 2×10⁻³ = 300 × 10⁻⁶
(3×10⁻³)²        = 9 × 10⁻⁶
```

这一招能覆盖所有光学题，不需要计算器写到小数点后很多位。

### 3. 小角度近似

`sinθ ≈ tanθ ≈ θ`，且 `θ` 用弧度。

适用条件：θ < 5° 左右。光学题里几乎所有角度都满足。

**这三个要在第一次用到时抽出来单独讲，讲完各出一道一秒题。** 塞进模型里讲会被跳过。

## 六、九个模型的标准讲法（波动光学完整示例）

这一节是模板，其他课程照这个结构替换。

### 1. 双缝干涉

- **定位**：两条平行的细缝，光穿过后来比路程
- **图样**：等间距、等亮的直条纹（和单缝最大区别）
- **骨架**：`x·d/L = kλ`，亮纹
- **符号表**：d 缝距 / L 屏距 / x 屏上中央到某点
- **挂钩**：没有 2（两束光各走一趟，不往返）
- **坑**：x 和 Δx 混（x 是中央到某条，Δx 是相邻两条之间）
- **一秒题**：第 3 级离中央 6 mm，第 1 级离中央多少？→ 2 mm

### 2. 薄膜干涉

- **定位**：一层薄薄的膜，上下两个表面各反射一束光
- **图样**：整片一个颜色（因为膜处处一样厚）
- **骨架**：`Δ = 2nd + λ/2`（翻一次加，翻两次不加）
- **符号表**：n 折射率（光慢几倍）/ d 膜厚 / λ 波长
- **挂钩**：2 = 光进膜一趟、出膜一趟
- **坑**：**两个面各查一次半波损失，不能只看一个**；翻两次就抵消
- **一秒题**：空气 1.0 → 膜 1.5 → 空气 1.0，下表面翻不翻？→ 不翻

### 3. 劈尖

- **定位**：两块玻璃夹一个小角，中间是三角空气层
- **图样**：平行于棱的等间距直条纹，**棱处是暗的**
- **骨架**：`Δ = 2nd + λ/2`；`Δd = λ/(2n)`；`Δx = λ/(2nθ)`
- **符号表**：θ 劈尖张角（rad）/ Δx 相邻条纹间距
- **挂钩**：**就是薄膜，只是膜厚从"处处一样"变成"按 x 线性变厚"**
- **坑**：`Δx` 的分母是 `2nθ`，不是 `2θ`（有膜时要乘 n）
- **一秒题**：棱处是明纹还是暗纹？→ 暗（d=0，只剩半波损失）

### 4. 牛顿环

- **定位**：平凸透镜压在玻璃板上，中间是球面形空气层
- **图样**：同心圆环，**内疏外密**，中心是暗斑
- **骨架**：暗环 `r_k² = kRλ/n`；明环 `r_k² = (2k−1)Rλ/(2n)`
- **符号表**：R 曲率半径 / r 环半径 / k 环序号
- **挂钩**：**就是劈尖，只是膜厚按 r² 长，所以条纹不等间距**
- **坑**：明环从 k=1 起（中心是暗的）；测 R 用 `R = (r²_{k+N} − r²_k)/(Nλn)`
- **一秒题**：中心那个点是亮的还是暗的？→ 暗

### 5. 迈克尔逊干涉仪

- **定位**：一台测极小长度的仪器，挪镜子、数条纹
- **图样**：同心圆环从中心冒出或缩回
- **骨架**：`2Δd = Nλ`
- **符号表**：Δd 镜子移动量 / N 移过条数 / λ 波长
- **挂钩**：**那个 2 和薄膜的 2 是同一个 2**（光去了还要回来）
- **坑**：忘乘 2（差一倍）；测折射率时改用 `2(n−1)L = Nλ`
- **一秒题**：挪镜 0.05 mm，λ=500 nm，移过几条？→ 200 条

### 6. 单缝衍射

- **定位**：一块挡光板开一条细缝（门缝），光散开
- **图样**：中间一条**特别宽**（约两侧的 2 倍）+ 两边越来越窄越暗
- **骨架**：`a·sinθ = kλ`，**算暗纹**，k 从 1 起
- **符号表**：a 缝宽 / θ 偏角 / k 第几条暗纹
- **挂钩**：和光栅只差字母（a ↔ d）
- **坑**：算的是暗纹不是亮纹；中央角宽度是 `2θ₁`（两个一级暗纹夹着）
- **一秒题**：第二级暗纹是第几条黑缝？→ 2

### 7. 圆孔衍射

- **定位**：圆孔（透镜口径、望远镜），中央亮斑叫艾里斑
- **图样**：一个圆亮斑 + 稀疏圆环
- **骨架**：`sinθ = 1.22λ/D`；屏上半径 `r = 1.22λL/D`
- **符号表**：D 孔径 / θ 第一暗环角半径 / L 屏距 / r 光斑半径
- **挂钩**：**就是单缝，只多乘一个 1.22**（因为边缘是弧，抵消稍晚）
- **坑**：漏掉 1.22；瑞利判据 `θ_min = 1.22λ/D`（D 越大分辨越细，不是放得越大）
- **一秒题**：D 变大，能分辨的细节变多还是变少？→ 变多

### 8. 光栅

- **定位**：一块玻璃刻了几千条等间距细线，等于很多条缝排成队
- **图样**：几根**极细极亮**的线 + 大片黑（和单缝的"一大片糊"完全不同）
- **骨架**：`d·sinθ = kλ`，**算亮线**，k 从 0 起
- **符号表**：N 刻线密度（条/mm）/ d 光栅常数（d = 1/N）/ a 缝宽
- **挂钩**：**和单缝只差一个字母**（a → d，暗 → 亮，k 从 1 → 从 0）
- **坑**：`d = 1/N` 出来是 **mm**，不换单位必错数量级；`k_max` 要**向下取整**
- **一秒题**：N = 1000 条/mm，d 比 1667 nm 大还是小？→ 小

### 9. 光栅缺级

- **定位**：本该亮的某条主极大凭空消失
- **图样**：屏上某几个位置是黑的（其余正常）
- **骨架**：`k = (d/a)·k′`
- **符号表**：k 亮线级次 / k′ 单缝暗纹级次（**k′ 从 1 起，没有 0**）/ d/a 比值
- **挂钩**：**光栅公式和单缝公式撞在同一方向**，相除就出来了
- **坑**：缺级 = d/a 的**所有倍数**；问"条数"要把缺的扣掉（不是 2k_max+1）
- **一秒题**：d = 4a，第 3 级看得见吗？→ 看得见（缺的是 4、8、12）

## 七、收束：一轮怎么结束

九个模型过完（或第一档过完），**必须做一次跨模型收束**，否则用户拿到的是九个碎片。

收束只做三件事：

### 1. 一张全景图

两大分支 + 每个分支下的模型清单。让用户看到"我一共学了几个、还剩几个"。

### 2. 一张"只有一列不同"的总表

**按"两束光多走的那段怎么算"组织，不按章节组织。** 这是最重要的一条组织原则。

| 模型 | Δ 等于什么 | 屏上形状 |
| --- | --- | --- |
| 双缝 | x·d/L | 等间距直条纹 |
| 薄膜 | 2nd + λ/2 | 整片一个颜色 |
| 劈尖 | 2nd + λ/2，d = xθ | 等间距直条纹 |
| 牛顿环 | 2nd + λ/2，d = r²/2R | 内疏外密圆环 |
| 迈克尔逊 | 2Δd | 圆环冒出 |
| 单缝 | a·sinθ = kλ | 中间特别宽 |
| 圆孔 | 1.22λ/D | 圆斑 + 环 |
| 光栅 | d·sinθ = kλ | 极细亮线 |
| 缺级 | k = (d/a)k′ | 某几条消失 |

**前三行公式完全一样**——这一句比讲十遍"注意区分"有用。

### 3. 一个通用解题顺序

给"拿到任何题先问哪四句"，比给公式表有用：

1. 两束光从哪来？→ 定模型
2. 多走的路怎么算？→ 写 Δ
3. 两个面各翻不翻？→ 决定加不加 λ/2
4. 要亮还是要暗？→ 令 Δ = kλ 或 (k+½)λ

## 八、节奏控制

实战数据（2026-11-13 ~ 15，约 12 小时，跨 3 天）：

| 内容 | 耗时 | 用户状态 |
| --- | --- | --- |
| 从"什么是波"补到"光程差" | ~90 分钟 | 反复卡，需退到 L-1 |
| 第 1 题（双缝） | ~40 分钟 | 卡在变式 |
| 第 2 题（薄膜） | ~60 分钟 | 卡在半波损失判断，错一次 |
| 第 3 题（迈克尔逊） | ~50 分钟 | 追问两次仪器外观，公式反而顺 |
| 第 4、5 题（单缝、光栅） | ~60 分钟 | 明显顺畅 |
| 九个模型串讲 + 收束 | ~120 分钟 | 从"问符号"转为"自己算" |

**观察到的拐点**：讲到第 5、6 个模型时，用户开始主动追问符号而不是说"不会"。**这是从"跟不上"转为"在建自己的表"的信号，此时不要加速，继续按七步走。**

**另一个信号**：用户连续追问"这东西长什么样""这条公式里每个符号什么意思"——说明他在补 L-1 层，不要催他做题。

**危险信号**：用户只回一个字（"不会""不知道""嗯"）。这表示已经掉线，必须立刻退一层，不要继续往下讲。
