# 零基础补课方法论

## 为什么要单独一层

考前求助的人里，**大多数不是"记不住公式"，而是"概念根本没建立"**。

直接上公式的后果是：他能抄下推导，但换个数就不会——因为他不知道每个符号在说什么。

补课不是"把教材重讲一遍"。它只做一件事：**把当前这道题真正需要的前置概念，补到刚好够用的程度。**

---

## 一、先分清两种"不会"

同一个"不会"，根子完全不同，处置方式也相反：

| 类型 | 表现 | 判定方法 | 处置 |
| --- | --- | --- | --- |
| **知识缺口** | 不知道有这个概念 | 换 2–3 种说法解释，仍然不懂 | 退到更基础的一层，重新讲 |
| **讲法问题** | 概念知道，但我的表述跨了步 | 换一种说法，立刻懂了 | 换讲法，**不降低内容难度** |

判定动作只有一个：**换一种说法再问一次。**

- 换了能懂 → 讲法问题，改表述，不退回
- 换了还不懂 → 知识缺口，往后退一层

误判的代价很大：
- 把讲法问题当缺口 → 学生被反复灌已经懂的东西，失去耐心
- 把缺口当讲法问题 → 一直换说法，越换越绕，学生会觉得"我就是笨"

---

## 二、诊断阶梯

按抽象程度从高到低分五层。**从上往下问，答不上就退一层。**

| 层 | 问什么 | 判据 |
| --- | --- | --- |
| L4 应用 | 这道题你会做吗 | 会 → 不用补课，直接讲题 |
| L3 规则 | 你知道该用哪条规则吗 | 知道 → 缺的是熟练度，练题 |
| L2 机制 | 你知道为什么是这样吗 | 知道 → 缺的是记公式 |
| L1 概念 | 你知道这里每个词的意思吗 | 知道 → 缺的是现象直觉 |
| L0 现象 | 这个现象你见过吗 | 见过 → 从类比讲起 |

### L0 之下还有一层：实物层

2026-11-13 实战发现，零基础用户会卡在比"现象"更底下的一层：**他不知道这东西长什么样、是干什么用的。**

| 层 | 问什么 | 症状 | 处置 |
| --- | --- | --- | --- |
| **L-1 实物** | 这东西长什么样、干嘛用的 | 反复问"什么叫 XX""长什么样""这是啥" | 先给外观图 + 一句"它是干什么的"，再谈原理 |

**识别信号**：用户在讲完原理后，仍然追问名称本身（"什么叫迈克尔逊干涉仪"），而不是追问公式。

**为什么必须先讲实物**：公式描述的是这个实物的行为。不知道实物是什么，公式就是一串无意义的符号，记不住也用不上。**先有东西，再有规律。**

讲实物的三段式：

1. **一句话定位**：它是一台测极小长度的仪器 / 它是一块挡光的板子
2. **外观图**：俯视或剖面，标出每个部件在哪、长什么样、手碰哪里
3. **它输出的读数**：屏上的条纹、指针的位置——用户"看到"的那个东西

> 注意：考试不考外观，但外观是理解的脚手架。讲 3–5 分钟就够，不要陷进去。

### 探测题的四条硬要求

1. **不用公式**
2. **不需要计算**
3. **答案是一两个字**（亮/暗、是/不是、变大/变小）
4. **答对就说明这层通了**，不用再问第二道

反面例子：
- ❌ "你能说说干涉的条件吗"（开放题，答不上不能说明什么）
- ✅ "两束光差半个波长，碰在一起是亮还是暗"（封闭题，一秒能答）

### 物理光学的现成阶梯

| 层 | 探测题 | 答不上就退到 |
| --- | --- | --- |
| L3 | 两束光差 1 个波长，亮还是暗 | L2 |
| L2 | 走一个波长，会不会回到原来的位置 | L1 |
| L1 | 波的峰和谷分别是什么 | L0 |
| L0 | 什么是波 | 画图，从"抖一下绳子"讲起 |

## 三、一个概念怎么讲（四步）

```
第 1 步  给一个身体能感知的类比
第 2 步  指出类比里对应的那个量（一一对应，不许多）
第 3 步  只定义这一个量，不引入任何新符号
第 4 步  立刻问一个"一秒题"验证
```

**一次只讲一个概念。** 一句话里塞两个新词，等于两个都没讲。

### 好 / 坏对照

**坏**：

> 光程差是两束光的光程之差，光程等于折射率乘以几何路程，当光程差为波长整数倍时干涉相长。

问题：一句话里有"光程差""光程""折射率""几何路程""干涉相长"五个新词。零基础的人读完一个都不剩。

**好**：

> 两个人从同一点出发，走到同一个地方。一个绕了远路，一个走近路。到了之后，两人迈的步子对不上。
> 光也一样。它有个天然的单位叫波长。
> 走的路相差整数个波长 → 步调一致 → 亮。

先用生活场景建立直觉，再挂术语，术语只挂一个。

### 手法 A · 符号逐字翻译法

遇到复合符号（`2nd`、`a·sinθ`、`kλ`），不要一句话带过，**逐字列表**：

| 符号 | 是什么 |
| --- | --- |
| `d` | 膜的厚度，题目要你求的未知数 |
| `2` | 光走两趟：进去一趟、出来一趟 |
| `n` | 光在膜里慢几倍 |
| `2nd` | 就是 2 × 1.5 × d，也就是 3d |

然后**立刻把符号式变成纯数字式**（`3d = 600`），让剩下的只有算术。

关键动作：**先消灭符号，再交给算术。** 零基础用户卡在 `2nd = kλ` 这类式子上时，往往是卡在"这串字母是什么意思"，不是卡在方程解法。

### 手法 B · 数轴法（凡是"谁大谁小"的判断都用）

涉及两个量比较的判断（疏/密、快/慢、高/低），**文字说"疏密"没用，必须画数轴**：

```
1.0（空气）—— 1.5（膜）—— 1.7（玻璃）
                            ↑ 往右 = 更密
```

用户只需看箭头往哪边，就能判断。2026-11-13 实测：用户看到"1.5 → 1.7"时凭"都是固体"误判为不翻；改成数轴后立刻能自己判断。

**通用教训：凡是"比较"类判断，给尺子，不给形容词。**

### 手法 C · 迁移复用（旧概念是新概念的地基）

每讲一个新概念，**先问一句：这个和之前学过的哪个是同一个道理？**

实战例子：

| 新概念 | 复用旧概念 | 复用话术 |
| --- | --- | --- |
| 薄膜光程差 `2nd` 的 2 | — | "光进膜一趟、出膜一趟" |
| 迈克尔逊 `2d` 的 2 | 薄膜的 2 | "跟刚才那个 2 完全一样，都是往返" |

迁移成功时，新概念的讲解成本接近零。**先找共性，再讲差异。**

## 四、常见缺口清单

按学科列出最常缺的前置。命中就优先补这个。

### 数学（几乎所有理科都会缺）

| 缺口 | 症状 | 一句话补法 |
| --- | --- | --- |
| 三角函数 sin/cos | 看到 sinθ 就卡 | "sin 是直角三角形里，对边比斜边" |
| 小角度近似 | 不理解 sinθ ≈ θ | "角很小时，弧长≈直线，所以 sinθ≈θ" |
| 指数运算 | 10⁻⁷/10⁻⁴ 算错 | "同底数相除，指数相减" |
| 科学计数法 | 单位换算丢数量级 | "小数点挪几位，指数就变几" |
| 函数与变量 | 不知道 f(x) 在说什么 | "给一个输入，按规则出一个输出" |

### 物理

| 缺口 | 症状 | 一句话补法 |
| --- | --- | --- |
| 波的图像 | 分不清横波纵波、峰谷 | 画一条绳子，抖一下 |
| 相位/步调 | 不懂"差半个波长" | 两个人走路，一个左脚一个右脚 |
| 矢量 | 力/速度的方向处理错 | "有大小也有方向，要分开算" |
| 微元思想 | 不懂为什么能"取一小段" | "把大东西切成无穷多小片，每片当直线" |
| **折射率 n** | 看到 n 不知道是什么 | "光在里面慢几倍"，配一张空气/玻璃波长对比图 |
| **相长 / 相消干涉** | 和"亮 / 暗"对不上号 | "相长就是亮，相消就是暗，同义词，只是卷子用正式名" |
| **半波损失** | 以为"损失了光能量" | "反射时波形翻个身，等于多走半个波长"，配翻转波形图 |
| **干涉仪 / 光栅等仪器** | 只认公式不认装置 | 先给外观 + "它是干嘛用的"，见 L-1 实物层 |
| **复合符号（2nd、a·sinθ）** | 不知道每个字母在说什么 | 逐字列表格翻译，见下方"符号逐字翻译法" |

### 化学

| 缺口 | 症状 |
| --- | --- |
| 摩尔 | 不知道 mol 是什么 |
| 化学平衡 | 分不清"反应完了"和"平衡了" |

### 经济/金融

| 缺口 | 症状 |
| --- | --- |
| 边际 | 以为是"边缘" |
| 弹性 | 不知道是"变化率之比" |
| 现值/终值 | 时间价值不直观 |

### 编程

| 缺口 | 症状 |
| --- | --- |
| 变量与作用域 | 不知道变量在哪有效 |
| 引用 vs 值 | 改了 A，B 也变了 |

## 五、讲法问题自查清单

每次讲完一段，自己过一遍。命中任意一条，说明是讲法问题，不是学生的问题：

- [ ] 用了还没定义过的符号
- [ ] 跳过了"为什么是这一步"
- [ ] 一句话里出现两个以上新概念
- [ ] 用了"显然""容易看出""众所周知"
- [ ] 用抽象表述代替具体例子（"走了 3 个波长" vs "走完三整圈又多走半圈"）
- [ ] 只给了一种讲法，没有备用说法

## 六、时间预算

| 模式 | 补课时间占比上限 |
| --- | --- |
| 急救（≤8h） | 20%，且只补当前考点直接需要的 |
| 冲刺（8–25h） | 30% |
| 常规（>25h） | 不限，可系统重建 |

超过上限说明两件事之一：
- 这个考点的前置链太长，本次时间不够 → 换更容易得分的考点
- 整体基础比预想的差 → 上调模式（急救→更激进的取舍），如实告诉用户

**不要用补课掩盖"时间不够"这个事实。** 该取舍就取舍，别假装能补完。
