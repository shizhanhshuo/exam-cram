# 取题策略

## 先判定路径

盘点用户材料，回答一个问题：**有没有试卷？**

| 材料情况 | 路径 |
| --- | --- |
| 有往年试卷（PDF / 图片 / 文字） | A 解析 |
| 只有复习提纲 / 课件 / 笔记 | B 检索 + 提纲作考纲 |
| 什么都没有 | B 检索（预期最低） |
| 卷子 + 提纲都有 | A 为主，B 补缺年份与题型分布 |

**提纲 > 卷子。** 如果老师划了重点，那就是最准的考纲，直接以它为准，卷子只用来验证。

---

## 路径 A：解析上传材料

### 处理步骤

1. **读全文**。PDF 用文本层，扫描件 / 照片走 OCR。OCR 后必须回看图像校对公式和下标 —— 数学符号 OCR 错误率极高，`∫` 和 `f`、`x₁` 和 `x1` 经常混。
2. **切题**。按题号切分，编号 `Q<年份>-<序号>`。没有年份就按文件名或页码推断，推不出标 `Q-unknown-<序号>`。
3. **每题抽六个字段**：

   | 字段 | 说明 | 缺失时 |
   | --- | --- | --- |
   | 年份 | 哪一届 | 标 unknown |
   | 题型 | 选择/填空/计算/证明/简答/论述/设计 | 按形式判 |
   | 分值 | 卷面分 | 按题型估，标「估」 |
   | 题干 | 原文 | — |
   | 考点 | 三级标签（见 analysis.md） | 必填 |
   | 难度 | 易/中/难 | 按步骤数估 |

4. **归并同题**。题干骨架相同、只有数字或情境不同的，算同一道题的不同版本，合并计数但保留变体。
5. **产出 `materials.md`**：题目清单表 + 来源说明 + 可信度。

### 分值估算表（卷面没标分时用）

| 题型 | 常见分值 |
| --- | --- |
| 选择 / 判断 | 2–3 |
| 填空 | 2–4 |
| 简答 / 名词解释 | 5–8 |
| 计算 | 10–15 |
| 证明 / 论述 | 12–20 |
| 综合大题 | 15–25 |

标注为「估」，并在热力表里注明按估算排序。**不要假装是准确值。**

## 路径 B：主动检索

### 残酷的现实（先想清楚，别给用户虚假希望）

大学**专业课**真题在公网命中率很低，通常 20–40%。原因：卷子不外流、老师轮换、院系自己存档。

**公共课**（高数、大英、思政、大物）命中率高得多，能到 60% 以上。

所以对专业课，检索只是三条腿中的一条，另外两条是**教材课后题**和**人际渠道**。

### 来源优先级（按性价比排，不是按顺序全做）

| 优先级 | 来源 | 为什么 | 怎么拿 |
| --- | --- | --- | --- |
| ★★★★★ | **教材课后习题 + 例题** | 大学老师出卷最大素材库，计算题常直接改数字 | 搜教材名 + 课后习题答案 |
| ★★★★★ | 老师给的复习提纲 / PPT / 习题课材料 | 等价于考纲 | 让用户翻班群、学习通、雨课堂 |
| ★★★★☆ | 同教材、同版本的**其他学校**卷子 | 教材一样，考点结构高度重合 | 搜「教材名 + 期末试卷」 |
| ★★★★☆ | 该课程的**考研真题** | 若这门课是考研科目，真题质量最高、命题最规范，考点覆盖全 | 搜「课程名 + 考研 + 真题」 |
| ★★★★☆ | **高校院系官网挂的原始 PDF** | 实测命中率最高的一类。不少学院有试卷库页面，PDF 直链形如 `院系域名/_upload/article/files/....pdf` | 搜 `site:edu.cn <课程名> 期末 试卷 filetype:pdf` |
| ★★★★☆ | **学科垂直试卷站** | 高数、大物、数据结构等公共基础课有专门站，题面完整带答案，比文库干净 | 搜「<课程名> 期末试卷 解答」看是否命中这类站，命中即深挖站内 |
| ★★★☆☆ | **CSDN / 博客园 / 语雀上的学生整理** | 常有"我校近三年真题"+ 网盘链接，是拿到本校卷的真实渠道 | 搜「<学校> <课程> 期末试卷 CSDN」 |
| ★★★☆☆ | 超星 / 学习通 / 中国大学MOOC 同名课程 | 有作业与测验，风格接近 | 平台内搜课程名 |
| ★★☆☆☆ | 百度文库 / 豆丁 / 道客巴巴 | 常在付费墙后，只能读到标题和预览页 | 搜 `site:wenku.baidu.com` |
| ★★☆☆☆ | 知乎 / 小红书 / 贴吧 / B站 | 拿不到卷子，但**"考了什么题型"的经验帖极有用** | 搜「学校 + 课程 + 期末 难吗」 |
| ⛔ | 人人文库 / renrendoc 等"2026 年 XX 期末试卷" | **大概率是假真题**，见下节 | 不用 |
| ★☆☆☆☆ | 淘宝 / 学长的资料店 | 有，但需付费，且质量不确定 | 告知用户自行判断 |

### ⛔ 假真题识别（必读，不识别会导致排序列全错）

实测发现：搜索「XX 期末试卷」时，大量结果标题形如「2026 年大学 XX 期末试卷及答案」，来自人人文库、道客巴巴等文档站。**这类基本不是任何一所学校的真题**，而是题库系统按教材章节拼的通用卷，或者是 AI 批量生成的。

特征：
- 标题带年份但没有学校名
- 页面内"参考答案"格式高度统一、题题都有详细解析
- 题目是教材概念的机械排列，没有出题人的取舍痕迹
- 同一站点对几十所学校、上百门课都有"2026 年试卷"

判定为假真题的，标 ⛔，**不进 materials.md 的统计，只能当练习题**。

真真题的样子：有学校名、有学年学期（如"2019-2020(2)"）、有具体的分值分配、解析里会提到"不唯一""按步骤给分"这种只有教研室才写的话。

### 搜索词模板

中文优先，英文兜底（中外合作办学、英文授课课程用得上）。

```
{学校} {课程全名} 期末试卷
{学校} {课程全名} 期中 真题
{学校} {学院} {课程} 复习 题型
{课程全名} 期末试卷 site:wenku.baidu.com
{课程全名} 考试 重点 笔记
{教材名} {作者} 课后习题 答案
{课程全名} 考研 真题 解析
{course name} past exam {university} filetype:pdf
{course name} final exam solution
```

### 实测有效的搜索式

优先级从高到低，命中就停：

1. `site:edu.cn <课程全名> 期末 试卷 filetype:pdf`
   → 直接命中高校官网原始 PDF。实测高数类命中率最高，命中后要深挖同域名下的其他年份（同一路径常有多年卷）。
2. `<学校> <课程全名> 期末试卷 CSDN`
   → 学生整理的"我校近几年真题"，常带网盘链接。
3. `<课程全名> 期末试卷 解答 大题`
   → 找学科垂直站，这类站的题面完整、带步骤分。
4. `<教材名> 课后习题 答案`
   → 保底，必有收获，且是老师出题的最大素材库。
5. `<课程全名> 考研 真题`
   → 仅当该课是考研科目，用作考点权重参考。

技巧：
- 课程名用**全称**，别用简称（"数据结构与算法"比"数构"好搜）
- 加上**教材名**往往比加学校名更有效 —— 同教材的卷子跨校通用
- 逐年搜（`2024 期末` / `2023 期末`），一次搜多年命中率更高
- 搜不到卷子就搜**题型描述**，经验帖里"考了三道计算一道证明"这类信息价值很高
- 命中 `/_upload/article/files/` 形式的长 PDF 链接，多半是教务处或院系上传的真卷，优先抓

### 可信度分级（每份材料必须标）

| 标记 | 含义 | 怎么用 |
| --- | --- | --- |
| ✅ 本校本科 | 有校名 + 课程号 + 年份，确认是这门课 | 全权重，可直接算频率 |
| 🟡 同课异校 | 课程名相同，学校不同，教材可能相同 | 权重 ×0.7，只用于考点结构 |
| ⚠️ 同教材异校 | 教材一致，课程名可能不同 | 权重 ×0.5，只用于考点权重 |
| 🔵 考研真题 | 命题方不同，但覆盖该课核心 | 权重 ×0.6 |
| ❌ 无来源 | 模型凭常识生成 | **禁止计入频率**，只能当"可能有" |

**红线：把 ❌ 混进频率统计，是最严重的错误。** 会让排序列完全失真，学生按错的顺序复习。

## 一份都搜不到时（标准兜底）

不要道歉，不要空手而归。按这个顺序给东西：

> 公开渠道没找到 XX 学校这门课的真题 —— 这是常态，大学专业课卷子基本不外流，不是你的问题。
>
> 换成三条替代路径，效果打八折但能救命：
>
> 1. **教材课后题**（老师出题第一大来源，计算题常直接改数字）—— 我现在就按你这本教材的章节重要性排一遍
> 2. **同教材其他学校的卷子** —— 教材一样，考点结构八成重合
> 3. **你班群 / 学委 / 学长** —— 这条最快，一句话问出来的东西我搜两小时也不一定有
>
> 下面的考点权重是我按「该课程通用命题规律 + 教材章节权重」推的，**标注为「推断」**，不是真题统计。你拿到真卷子后我们重算一次。

然后照常往下走 Stage 2，但热力表里每行都要带「推断」标记。

## 混合场景的处理

常见情况：用户有 1 份卷子，搜到 2 份同教材异校卷。

处理：

1. 本校那份定**分值结构**（题型分布、每题多少分）—— 这是最准的信息
2. 异校卷定**考点覆盖**（哪些知识点反复出现）
3. 教材课后题定**具体题目**（复习时练什么）
4. 三者交叉：出现次数 ≥2 次的考点，直接进第一档

在 `materials.md` 里写清楚哪份材料承担什么角色，别混着算。
