# 考点提取与排序

## 一、打标签

每道题打三级标签，格式 `章 / 知识点 / 具体考法`。

```
第3章 微分中值定理 / 罗尔定理 / 三段条件核对+构造辅助函数
第5章 长期股权投资 / 权益法 / 被投资方净利润调整
```

### 粒度判据

| 太粗 | 刚好 | 太细 |
| --- | --- | --- |
| 「微积分」 | 「罗尔定理」 | 「用罗尔定理证明 x³−3x 在 [−1,1] 有驻点」 |
| 「会计」 | 「权益法下净利润调整」 | 「甲公司持有乙公司 30% 股权时的调整」 |

**标准：一个标签 = 一次课能讲完的一个概念，或一种题型。** 判据是"能不能一次性讲透"。

### 合并同义标签

同一知识点的不同问法必须合并，否则频率算不出来：

- 「用罗尔定理证明」「验证罗尔定理条件」「找驻点」→ 合并为 `罗尔定理`
- 「求逆矩阵」「用初等变换求逆」→ 合并为 `矩阵求逆`

合并后保留具体考法作为子标签，用于判断"老师偏好哪种问法"。

## 二、权重公式

```
Score = 0.35 × 频率 + 0.30 × 分值占比 + 0.20 × 新近度 + 0.15 × 章节权重
```

四个因子都归一化到 0–100。

### 频率

```
频率 = 出现该考点的卷子数 / 总卷子数 × 100
```

同一份卷子多次出现只算 1 次（避免一道大题拆成三小问被算成 3 次）。

### 分值占比

```
分值占比 = (该考点各年分值之和 / 年数) / 卷面总分 × 100
```

单年均值，除以满分。反映"这个考点每次考试值多少比例的分"。

### 新近度

| 最近一次出现 | 得分 |
| --- | --- |
| ≤1 年 | 100 |
| 2 年 | 70 |
| 3 年 | 40 |
| ≥4 年 | 20 |
| 从未出现 | 0 |

理由：老师命题习惯变化慢，但也有轮换。近两年出现的考点，重复概率显著更高。

### 章节权重

优先用老师给的信息，依次降级：

1. 复习提纲里标了"重点" → 100，标了"了解" → 30
2. 课时占比（用户能回忆出老师讲了几周）→ 按比例
3. 教材该章页数占比 → 按比例
4. 无信息 → 50（中性）

## 三、样本不足时的退化

这是**最常见的情况**，必须处理好，否则算出来的序是假的。

| 样本量 | 调整 |
| --- | --- |
| ≥4 份本校卷 | 全公式可用 |
| 2–3 份本校卷 | 频率因子可信度一般，权重降到 0.25，分值占比升到 0.35，新近度 0.25，章节 0.15 |
| 1 份本校卷 | **频率无意义**，弃用。改用 `0.45 × 分值占比 + 0.30 × 章节权重 + 0.25 × 题型重要性` |
| 0 份本校卷（纯推断） | 弃用频率与分值占比。改用 `0.55 × 章节权重 + 0.30 × 该课通用高频考点先验 + 0.15 × 题型重要性` |

**退化后必须在热力表标注「样本不足，排序仅供参考」。** 不标就是骗人。

### 通用高频考点先验（无样本时用）

多数大学课程的命题分布有共性，可作为弱先验：

- 基础概念辨析、定义判断 → 几乎必考，低分值
- 核心计算 / 推导方法 → 高频，高分值
- 综合应用题（跨章）→ 常作为压轴，高分值
- 边缘章节、教材最后两章 → 低频，常跳过（时间紧时优先放弃）

## 四、三条分数线

按 Score 降序排列后，累计分值占比划线：

```
累计 60%  → 及格底线（急救模式必须全做完）
累计 80%  → 稳过线（冲刺模式目标）
累计 95%  → 冲高线（常规模式才碰）
```

线的意义：告诉学生**"复习到这里就能及格了"**。这是突击党最需要的心理锚点 —— 否则他会以为要全学完，然后直接摆烂。

计算时用「年均分值」累加，不用 Score 累加（Score 是相对序，不是分值）。

## 五、命题风格判断

除排序外，还要读出四件事，写进作战计划：

### 1. 题型结构是否固化

统计各题型的分值占比。若某题型每年占比波动 <5%，说明结构固定，可按固定配比准备。

若存在"必考题"（如每年必有一道 20 分综合题），单独标出，优先级拉满。

### 2. 原题重现率

对比各年题目，骨架完全一致（只改数字/情境）的比例：

- \>30% → **原题重现明显**，往年题优先级最高，直接背解法模板
- 10–30% → 有改题习惯，往年题要做但要理解
- <10% → 爱出新题，必须懂原理，不能只背套路

### 3. 考概念还是考计算

- 计算题占比 >60% → 主攻套路与计算速度，背模板有效
- 概念题 / 简答占比 >50% → 主攻术语精度与框架，背模板无效，要能自己组织语言
- 各半 → 两条线并行

### 4. 难度分布

按"步骤数"粗估：1–2 步 = 易，3–5 步 = 中，>5 步 = 难。

若卷面易:中:难 ≈ 6:3:1（常见），则**先吃光易题**，性价比最高。
若难:易 ≈ 4:6（部分专业课压轴难），则易题吃完后必须攻一道难题，否则上不了 75。

## 六、考点热力表输出

用 `assets/考点热力表模板.md`，格式：

| # | 考点 | 章 | 出现年份 | 频次 | 年均分值 | 占比% | 新近度 | Score | 累计% | 档位 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | 罗尔定理 | 3 | 21,22,23 | 3/3 | 12 | 12% | 100 | 88.5 | 12% | 🔴必做 |
| 2 | 拉格朗日 | 3 | 21,23 | 2/3 | 9 | 9% | 100 | 79.2 | 21% | 🔴必做 |
| … | | | | | | | | | 60% | ← 及格线 |
| … | | | | | | | | | 80% | ← 稳过线 |

档位标记：
- 🔴 必做（在 60% 线内）
- 🟠 重要（60–80% 线）
- 🟡 选做（80–95% 线）
- ⚪ 放弃（95% 线外，或时间不够时直接砍）

**⚪ 那一档必须显式列出来。** 告诉学生"这些不用看"比告诉他"这些要看"更有价值 —— 省下的时间是突击党的命。

## 七、分数账本

一个持续更新的表，放在作战计划里：

```
目标：75 分
已锁定：34 分 ██████░░░░░░░░ 45%
今日计划：+18 分（考点 #5 #6 #7）
剩余需：41 分 / 可用 11 小时 → 3.7 分/小时
```

规则：
- 「已锁定」= 自测通过的考点分值，不是"看过"的分值
- 每完成一个考点立刻更新，给即时反馈
- 若「剩余需 / 可用小时」> 5 分/小时，说明目标定高了，当场下调并说明
- 若 < 1 分/小时，触发劝停（见 SKILL.md Stage 5）

## 八、自测记录结构

`03-自测记录.md`：

| 时间 | 考点 | 变式题 | 结果 | 错因归类 | 处置 |
| --- | --- | --- | --- | --- | --- |
| D1-20:15 | 罗尔定理 | 构造 g(x)=f(x)−kx | ❌ | 概念不懂 | 重讲构造思路 |
| D1-20:30 | 罗尔定理 | 验证三条件 | ✅ | — | 锁定 12 分 |

错因四分类（决定处置方式）：

| 错因 | 表现 | 处置 |
| --- | --- | --- |
| 概念不懂 | 说不出这步为什么这么做 | 换讲法重讲，不许重复原话 |
| 记忆缺口 | 知道思路，忘了公式 | 只补公式 + 做 1 道同类 |
| 计算出错 | 思路对，算错 | 只补计算，重讲概念是浪费时间 |
| 审题失误 | 看漏条件、答非所问 | 教审题动作：圈条件、标问号 |

**同一个考点连续 2 次「概念不懂」→ 停下，回去补前置。** 硬推下去只会累积挫败感。
