# 学科分层

## 为什么必须分层

同一套讲法在物理上有效，在思想政治上会失效；同一套验证方式在经济学会漏坑，在数据结构上会跑偏。

差别不在"难易"，在四件事：

| 差异项 | 说明 |
| --- | --- |
| **卡在哪一层** | 物理卡符号层，法学卡名词层，医学卡名词海+机制顺序 |
| **怎么验证算懂** | 物理问"变大变小"，法学问"属于哪一类"，代码问"输出什么" |
| **图要画什么** | 物理画装置，经济画坐标系，代码画内存/流程 |
| **分从哪来** | 物理靠步骤分，经济靠作图踩点，人文靠分点答题 |

**不分层的直接后果**：用讲物理的手法讲法学（画一堆图，学生一个定义没记住），或用背法条的手法讲电路（背了一堆公式，一道题不会做）。

---

## 第一步：判定学科族

从**课程名 + 材料特征**判，不要问用户"你这门课属于哪类"——他答不出来。

| 族 | 名称 | 典型课程 | 判定信号 |
| --- | --- | --- | --- |
| **A** | 计算型理科 | 高数、线代、概率统计、大学物理、电路、理论力学、化工原理、信号与系统 | 卷面大量推导与数值计算；PPT 公式密集；答案要带单位 |
| **B** | 图形·概念型经管 | 微观/宏观经济学、金融学、会计学、管理学、市场营销 | 有坐标系图（供需、成本、无差异曲线）；表格数据多；简答+作图并存 |
| **C** | 记忆·论述型人文社科 | 思政、马原、法律、历史、教育学、文学、新闻传播 | 大段文字；名词解释/简答/论述；PPT 图少字多 |
| **D** | 代码·工程型 | 数据结构、操作系统、计算机网络、数据库、软件工程 | 代码/伪代码；复杂度；设计题；要求画结构图或流程图 |
| **E** | 机制·术语型医学生物 | 解剖、生理、病理、生化、药理、免疫 | 术语海；机制链条；图像识别；病例分析 |

**判定优先级**：课程名命中典型课 > 材料特征 > 用户描述。三者冲突时以材料特征为准（课程名经常有迷惑性，如"经济数学"其实属于 A）。

### 跨族课程怎么办

很多课是混血：生物化学（E+A）、金融工程（B+A）、计量经济学（B+A）、医学统计学（E+A）、管理信息系统（B+D）。

处理：**定主族 + 副族，主族走流程，副族只补差异。**

```
主族 = 决定章节目录和讲法骨架的那一族
副族 = 决定题目形态的那一族
例：生物化学 → 主 E（术语与机制）· 副 A（计算题、公式推导）
    计量经济学 → 主 B（概念与解释）· 副 A（回归计算）
```

卡在某一步时，先判断它属于主族问题还是副族问题，再翻对应的章节。

## A · 计算型理科

### 卡点分布（按实际频率）

```
名词层 ★★★☆☆
实物层 ★★★★☆   ← 零基础最常卡在这里
比较层 ★★★★☆
符号层 ★★★★★   ← 第一杀手
公式层 ★★☆☆☆   ← 反而最不容易卡
计算层 ★★★★☆   ← 单位换算、取整
```

**核心结论：公式层是最后一层，不是第一层。** 学生说"不会做"，八成不是公式没记住，而是不知道符号指什么、不知道装置长什么样。

### 一秒题形态

- **方向题**：这个量变大，那个变大还是变小？（两个选项）
- **归属题**：这个符号在图上量的是哪一段？（三个选项）
- **判断句**：差整数个波长，是亮还是暗？

**禁用**：任何需要两步以上推导的问题。

### 必须画的图

| 图 | 用途 |
| --- | --- |
| 装置/结构图 | 标出题目给的那个尺寸在哪 |
| 每个符号的"图上哪一段"标注图 | 替代文字描述 |
| 波形/曲线图 | 建立趋势直觉 |

讲完必附**四列符号表**：`字母 | 图上是哪一段 | 题目常见说法 | 单位`。

### 得分密度最高的动作

1. **大题第一问**（通常是套基础公式，白送分）
2. **写公式 + 统一单位**（不做完也有步骤分）
3. **典型装置的标准化解法**（同一个模型反复考）

### 保底写法

```
1. 抄下用到的公式（哪怕没算）
2. 写"已知：… 求：…"
3. 全部换成国际单位或统一单位
4. 代入数字，写清单位
5. 结果加一句结论（"故 d = 100 nm"）
```

只做前 3 步通常能拿该题 1/3 的分。

### 时间分配

概念补课 **40%** ／ 做题与变式 **60%**。零基础可临时调到 60/40，但不超过。

### 常见 PPT 错误类型

- 公式系数错、上下标错、正负号错
- 上下角标在转 PDF 时丢失（`x2` 是 `x²` 还是 `x₂`）
- 沿用旧版符号（不同教材符号体系不同）
- 图与公式不符（图上标的角度和公式里的不一致）
- 例题数字算错（**一定要自己代一遍**）

### 高频陷阱

单位换算（mm/μm/nm 跨档）、小角度近似条件、取整方向（向下不四舍五入）、开区间与闭区间、有效数字。

## B · 图形·概念型经管

### 卡点分布

```
名词层 ★★★★★   ← 大量近义术语互相干扰
图形语言 ★★★★★  ← "移动" vs "沿曲线移动"
机制层 ★★★★☆   ← 为什么导致为什么
计算层 ★★☆☆☆   ← 通常只到四则运算
```

**核心结论：这族的难点是"名词之间长得太像"，不是难在数学。** 学生失分主要来自术语混淆和图的方向画反。

### 一秒题形态

- **方向题**：这个东西涨价，曲线往哪边动？
- **辨析题**：这是"整条线搬家"还是"沿着原线滑动"？（两选项）
- **归属题**：这属于三类的哪一类？

### 必须画的图

只画高频的 3–4 张，不要贪多：

| 族 | 核心图 |
| --- | --- |
| 微观 | 供需图（含移动与均衡）、剩余图（消费者/生产者剩余）、成本曲线、无差异曲线+预算线 |
| 宏观 | AD-AS、IS-LM（若考）、菲利普斯曲线 |
| 金融 | 现金流时间轴、收益-风险图 |

**每张图固定五步画法**：画轴 → 画初始曲线 → 标初始均衡 → 标移动方向（虚线+箭头）→ 写新均衡与结论一句话。

### 得分密度最高的动作

1. **作图题**（套路极固定，练三遍能满分）
2. **简答题**（按"定义 → 机制 → 结论"三段给分，写结构就有分）
3. **计算题里的面积计算**（剩余、无谓损失）

### 保底写法

```
画图（哪怕只画轴和一条线）
+ 标出移动方向
+ 写一句结论："因此均衡价格上升、均衡数量下降"
```

**作图题不画图 = 0 分，画了图哪怕分析错也有 2–3 分。**

### 时间分配

概念辨析 **30%** ／ 作图 **40%** ／ 计算 **30%**。作图的性价比远高于背概念。

### 常见 PPT 错误类型

- 中英两版课件术语不一致（同一概念两个中文译名）
- 图形方向画反（供给曲线画成右上、需求曲线画成右下，或移动方向标错）
- 案例数据过时（用十年前的 GDP、利率）
- 教材版本差异（高鸿业 vs 曼昆，同一概念的表述与图形细节不同）
- 把"需求量变动"和"需求变动"混写

### 高频陷阱

需求移动 vs 需求量变动；价格上限与价格下限搞反；消费者剩余与总剩余混淆；弹性大于 1 与小于 1 的方向；机会成本算成"总成本"而不是"放弃的量"。

## C · 记忆·论述型人文社科

### 卡点分布

```
名词层 ★★★★★   ← 定义必须精确，差一个字就丢分
结构层 ★★★★★   ← 答题要点怎么排
理解层 ★★★☆☆
```

**核心结论：这族不考"聪明"，考"结构 + 精确"。** 学生常以为自己"背了"，其实是"认得"，一提笔写不全。

### 一秒题形态

- **归类题**：这个词属于哪一类？
- **判断句**：某句话表述对不对？（一句话即可）
- **顺序题**：这几个步骤，哪个在前？

### 必须给的东西

不是图，是**答题骨架**：

```
【名词解释】定义（1句）→ 核心特征（2–3点）→ 意义/作用（1句）
【简答题】  ｜ 分点作答，每点一个短句，先写结论再解释
【论述题】  是什么 → 为什么 → 怎么办（或：背景 → 内容 → 评价）
```

### 得分密度最高的动作

1. **分点答题**（踩点给分，写成一整段必丢分）
2. **高频名词的标准化定义**（背 20 个比背 100 个有用）
3. **万能框架迁移**（同一框架套不同题）

### 保底写法

定义 + 特征 + 意义 三段，每段一到两句。**宁可写短写全，不要写长写偏。**

### 时间分配

框架 **50%** ／ 内容 **50%**。先记框架再填内容，反过来会背成一团乱麻。

### 常见 PPT 错误类型

- 政策表述、法条、数据过时（**这族最容易出错**，必须校对）
- 引文出处错（作者、年份、文献名）
- 与现行教材表述不符
- 概念层次混乱（把"特征"写成"意义"）

### 高频陷阱

只背不理解（换问法就废）；定义记个大概（少一个限定词就错）；要点写成一整段（阅卷找不到点）。

## D · 代码·工程型

### 卡点分布

```
机制层 ★★★★★   ← 为什么这么设计
手写能力 ★★★★★  ← 看懂 ≠ 写得出
名词层 ★★★☆☆
复杂度 ★★★★☆
```

**核心结论：这族最大的假象是"看懂了"。** 能读代码和能手写代码是两种能力，必须分开验。

### 一秒题形态

- **输出题**：给 5 行代码，输出是什么？
- **复杂度题**：这段循环是 O(n) 还是 O(n²)？
- **操作题**：对这个结构插入一个元素，谁指向谁变了？

### 必须画的图

| 场景 | 图 |
| --- | --- |
| 数据结构 | 内存布局图 / 节点指针图（画箭头，标空指针） |
| 算法 | 手工执行追踪表（每一步的变量值） |
| 协议/网络 | 时序图（谁发什么、谁回什么） |
| 系统 | 分层结构图 |

**链表、树、图必须手画，不许口头描述。** 指针题的失分几乎全部来自"没画图"。

### 得分密度最高的动作

1. **手写核心算法**（高频那 8–10 个，反复写到能默写）
2. **复杂度分析**（套路固定，练熟就稳）
3. **结构图/流程图**（画画就有分）

### 保底写法

```
1. 写出思路（自然语言，2–3 行）
2. 写伪代码或代码框架（哪怕有语法错）
3. 写出时间/空间复杂度
```

**代码跑不通也给分，思路空白才是 0 分。**

### 时间分配

机制理解 **30%** ／ 手写练习 **50%** ／ 概念背诵 **20%**。

### 常见 PPT 错误类型

- 课件代码本身有 bug 或伪代码不完整
- 复杂度标错
- 术语中英混用（同一概念两个译名）
- API 用法过时（旧版本语言标准）
- 图示与实际实现不符（如画的是单向链表但文字写双向）

### 高频陷阱

边界条件（空、单元素、满、越界）；指针与引用混淆；循环不变式说不清；把平均复杂度当最坏复杂度。

## E · 机制·术语型医学生物

### 卡点分布

```
名词量 ★★★★★   ← 数量太大，且形近词多
机制顺序 ★★★★★  ← A→B→C 顺序错就全错
结构定位 ★★★★☆
```

**核心结论：这族不是"记不住"，是"记混了"。** 相似名词必须成对讲，不能单独讲。

### 一秒题形态

- **功能题**：这个结构负责什么？
- **方向题**：这个刺激会使 X 升高还是降低？
- **归属题**：这个现象属于哪一类？

### 必须画的东西

1. **机制链条图**：`刺激 → 感受器 → 传入 → 中枢 → 传出 → 效应`，每一环标出关键递质或激素
2. **结构定位图**：这个东西在哪个位置、和谁相邻
3. **对比表（成对出现）**：形近词必须两两并列，不能分散讲

### 得分密度最高的动作

1. **名词解释**（定义 + 关键特征 + 举例）
2. **机制简答**（按链条顺序分步写，写到几环给几环的分）
3. **成对对比表**（抑制/兴奋、收缩/舒张、动脉/静脉）

### 保底写法

```
结构 → 功能 → 异常（或：定义 → 机制链 → 临床意义）
```

机制题哪怕只写出前两环也有分，**按环给分，不要空着**。

### 时间分配

术语与机制 **70%** ／ 练习 **30%**。这族不靠刷题靠结构化。

### 常见 PPT 错误类型

- 参考值、剂量、单位写错（**风险最高，必须核对**）
- 旧版分类标准（疾病分类、分期标准已更新）
- 机制图缺环或箭头方向错
- 中文译名与教材不一致

### 高频陷阱

形近词混淆；机制顺序颠倒（先有因还是先有果）；把"代偿"当"病因"；正常值范围记错方向。

## 族间迁移：什么时候可以复用讲法

只有一种情况可以直接迁移：**两个学科卡在同一层、同一类验证方式。**

| 可以迁移 | 理由 |
| --- | --- |
| A ↔ D | 都卡符号层/机制层，都用"画图 + 逐字翻译" |
| B ↔ C | 都靠结构化答题得分，都用"骨架先行" |
| E → A | 机制链条讲法可复用到物理的推导链 |

| 不能迁移 | 理由 |
| --- | --- |
| A → C | 理科靠图建立直觉，人文靠结构踩点，图在这里几乎无效 |
| C → A | 背定义对解题零帮助，反而占掉做题时间 |
| D → B | 代码的"看懂≠会写"在经管里不成立，经管是"会画图就会答" |
