# 材料校验与交叉验证

## 为什么必须有这一层

用户上传的课件、讲义、复习提纲，**是他手上最像"官方"的东西，但它不等于真理。**

课件出错的真实原因（不是小概率事件）：

| 原因 | 表现 |
| --- | --- |
| 排版/转换错误 | 公式上下标丢失、正负号消失、分数线错位 |
| 沿用旧版教材 | 第 7 版的讲法套在第 8 版教材上 |
| 老师笔误 | 例题数字算错、系数漏写 |
| 中英双版不一致 | 同一门课两套 PPT，术语甚至结论不同 |
| 内容过时 | 政策、法条、数据、API 版本已更新 |
| 跨章拼接 | 从别的课/别的老师那里搬来的页，体系不兼容 |

**核心原则：把上传材料当「待校验的线索」，不当「答案」。**

但不校验就讲，后果比不讲课更严重——学生会照着错的东西记，考场上按错的答，而且他不知道自己在错。**错的知识比没有知识更贵。**

---

## 三级校验（从低成本到高成本，能停就停）

### V1 · 内部一致性（必做，几乎零成本）

不用联网，只在材料内部对照。**九成的错误能在这里抓出来。**

| 检查项 | 怎么查 |
| --- | --- |
| 同一份 PPT 前后矛盾 | 定义在第 3 页，公式在第 20 页，两处对不上 |
| 多份 PPT 之间冲突 | 中英版、不同章节、两个学期版本互相比 |
| 与教学大纲冲突 | 大纲说考到第 5 章，PPT 里有第 7 章内容 |
| **例题数字能否算回去** | **自己代一遍。这一步抓错率最高，务必做。** |
| 图与公式是否一致 | 图上标的角度/符号，和公式里的是不是同一个 |
| 符号体系是否统一 | 同一份材料里同一个量用了两个字母 |

> **最有效的单项动作：把例题自己算一遍。** 老师笔误、公式抄错、答案写错，全在这一步暴露。而且它顺带就把讲题素材准备好了。

### V2 · 权威对照（关键结论必做）

一条结论要影响学生答题的，就要核。

| 顺序 | 对照源 | 怎么找 |
| --- | --- | --- |
| 1 | **教材原书**（用户有就给） | 让用户翻目录/拍照；或搜「教材名 + 第 X 章 + 定理名」 |
| 1.5 | **本校题库收录的教材 PDF** | 北邮：`byrdocs.org/?q=<教材名>`，书籍类结果带**出版社、ISBN、版次**——能确认是不是同一版，比网上的杂版可靠 |
| 2 | **多个独立来源交叉** | 至少 2 个互不相关的来源一致，才算确认 |
| 3 | **英文术语检索** | 中文资料质量参差，`<term> definition` 常能命中大学课程页 |
| 4 | **`site:edu.cn` / `site:.edu`** | 高校课程页、讲义 PDF，可信度高于文库站 |

**可信度排序（从高到低）**

```
教材原书 / 国家标准 / 官方文档
  > 高校课程页（.edu.cn / .edu）
  > 学科权威百科、经典教材配套答案
  > 技术博客、知乎高赞
  > 文库站、AI 生成内容站（不采信）
```

**红线：文库站、renrendoc、"2026 年 XX 期末试卷及答案"这类站点，不能作为校验依据。**

### V3 · 真题对照（有卷子时做）

如果手上有往年真题：

- 真题的标准答法**优先于** PPT 的表述
- 真题答法与 PPT 冲突时 → 按真题讲，并说明"课件这里写的是另一种说法，考试按真题这个来"
- 真题没覆盖的知识点 → 只能靠 V1 + V2

## 冲突处理决策树

发现不一致后，**必须分类处理，不能一律"以 PPT 为准"或"以我为准"**。

| 类型 | 判断依据 | 处理方式 | 是否告知用户 |
| --- | --- | --- | --- |
| **① 明显笔误** | 算错了、符号抄错、上下标丢失 | 按正确版本讲 | **必须说**："这里课件应该是 X，我按 X 讲" |
| **② 版本差异** | 两个教材/两个学派讲法不同 | 两条都讲，标明考试按哪条 | **必须说** |
| **③ 学术争议** | 学界未统一 | 讲主流答法 + 考试答法 | **必须说** |
| **④ 表述简化** | PPT 为省篇幅省略了条件 | 讲完整版，同时给"考试写简化版也行" | **建议说** |
| **⑤ 无法判断** | 两个来源矛盾且都不可靠 | 明确说"我不确定" | **必须说** |

### 三种绝对禁止的做法

| 禁止 | 为什么 |
| --- | --- |
| **静默按错的讲** | 学生记错、答错，且不知道自己在错 |
| **静默纠正不讲** | 学生按 PPT 背，考试按 PPT 答反而对；你讲的和他的材料不一致，他会混乱 |
| **编造出处** | 说"教材第 128 页就是这么写的"、"这是本校 2023 年真题原题"——没有就是没有 |

> **第二条最容易被忽略。** 有些错误 PPT 是无害的（老师自己也这么讲、考试也这么答），这时**不该改，但该提醒**：
> "课件这里写的是 A，学术上更准确是 B。**你这门课按 A 答就行**，别改。"

## 校验结果写在哪

### 在 `materials.md` 里加一节

```markdown
## 材料校验

- 校验时间：
- 校验级别：V1 内部一致性 ✅ / V2 权威对照 ✅ / V3 真题对照 ⬜（无卷子）
- 结论：主要材料可用，发现 N 处疑点

| 编号 | 位置 | 疑点 | 类型 | 处理 | 依据 |
| --- | --- | --- | --- | --- | --- |
| E1 | Ch4 P12 | 例题均衡价格算成 6，应为 5 | ① 笔误 | 按 5 讲 | 自己代算 |
| E2 | 中英版 Ch7 | 中文版"消费者剩余"对应英文版 consumer surplus，但英文版公式少 1/2 | ② 版本 | 讲中文版，注明英文版有误 | 教材第 8 版 |
```

### 疑点多且影响考点时，单独产出 `05-勘误表.md`

只在**疑点会改变答案**时才单独出文件。轻微笔误写进 materials.md 就够，不要让用户被一堆勘误淹没。

```markdown
# 勘误表 · <课程名>

> 这份表只列**会影响答题**的错误。轻微笔误已并入材料清单。

## 会影响得分的错误

### E1 · 薄膜干涉最小厚度公式（Ch2 P18）
- 课件写的：`d = λ/(4n)`
- 正确应为：`d = λ/(2n)`（反射相长取 k=1 时）
- 影响：按课件算会得到 100 nm，正确是 200 nm
- **考试怎么答**：按正确版（λ/2n），因为这是标准结论，老师不会按错的计算给分
- 依据：教材第 8 版 P112；两份独立来源一致

## 只影响表述、不影响答题
（略）
```

## 各学科的高危错误清单

按 `references/subjects.md` 的族分类，优先查这些位置。

| 族 | 高危项 | 后果 |
| --- | --- | --- |
| **A 计算理科** | 公式系数/上下标、近似条件、单位、图与公式不符 | 算出的数完全不同 |
| **B 经管** | 中英术语不一致、曲线移动方向画反、旧数据 | 作图题全错 |
| **C 人文社科** | 政策/法条过时、引文出处、教材版本表述 | 论述题答到旧标准上 |
| **D 计算机** | 代码有 bug、复杂度标错、API 过时 | 手写题按错的写 |
| **E 医学生物** | 参考值/剂量、机制顺序、旧分类标准 | 风险最高，必须逐条核 |

**E 族的参考值与剂量是最不能"凭印象"的一类** —— 记错一个量级就是医疗错误。核不到权威来源时，明确告诉用户"这个数请以你们教材为准，我不确定"。

## 实际执行节奏（别把校验做成负担）

校验不是一次性全做，是**按需触发**：

| 时机 | 做什么 |
| --- | --- |
| Stage 1 拿到材料 | 只做 V1（内部一致性 + 例题代算），10 分钟内 |
| 讲某个模型/考点前 | 对这一个点做 V2，只核这一条 |
| 发现疑点 | 走决策树，当场告知，记表 |
| 讲完一章 | 汇总一次，出勘误（若需要） |

**不做全量预校验。** 一门课 10 份课件全核一遍，时间成本超过复习本身，而且大部分内容永远讲不到。

> 原则：**讲到哪，核到哪。** 没讲到的内容不核，因为核了也用不上。
